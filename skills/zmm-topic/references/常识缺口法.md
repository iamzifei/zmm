# 常识缺口法：大切口是产物，不是起点

> 管三件事：**选题从哪来、标题从哪来、前 15 秒讲什么。**
> `zmm-topic` / `zmm-hook` / `zmm-title` 三个技能共用本文件。
>
> ⚠️ **别跟「信息缺口」混。** 信息缺口是「我知道你不知道」，用来留悬念；
> **常识缺口是「你以为你知道，但它解释不了眼前这件事」**，用来立选题。
> 前者是手法，后者是选题的来源。

---

## 它要解决的那个矛盾

标题和前 15 秒必须切**泛人群都关心的普遍问题**，否则没人进来。
但真正值钱的是**深的理论和判断**，那东西天然小众。

两边都要，怎么办：

> **切口要泛，理论要深。切口负责让人进来，理论负责让人觉得值。**
> 而切口是从理论里**长出来的**，不是从爆款榜上**抄来的**。

⚠️ **这句话在推翻一个流行的二元对立**：「泛流量播放高但转化差，精准流量播放低但转化好，
不可兼得」。**那个说法假设开口大小和内容深度是同一个旋钮的两端——它们是两个旋钮。**
🟢 一个独立来源同向确证了这条判断，展开见 `议程与合集.md` §四。

**一个可以拿来自查的反例**：直接发《什么是隐性成本》，没人看；
从「老实人为什么发不了财」切进去讲同一个理论，就能进大池。
**同一个内核，换一个开口，量级完全不同。**

---

## 🔴 为什么不能抄爆款标题

看到一个爆款标题，用自己的方案重讲一遍——这条路走不通，三个理由：

1. **标题一样就没有新鲜感。** 观众刷到的是第二遍，不是第一遍。
2. **内容很难讲出不同。** 标题定了框，你只能在他的框里说话。
3. **★ 抄标题就是抄结论。** 两个人可以得出同一个结论，但不会走同一条路（同〈亮路径三幕〉）。
   爆款标题是他走完全程之后的**产物**；你从产物开始，等于跳过了产生它的那条路，
   **而那条路才是唯一抄不走的东西。**

## ⓪ 起点：为了解决一个问题去搞懂一件事（2026-08-24 补）

**五步之前还有一步，而它决定了后面五步是真的还是装的。**

| ❌ 起点 | ✅ 起点 |
|---|---|
| 去刷别人做了什么，用自己的口吻再讲一遍 | **为了解决一个你真的卡住的问题，去把这件事搞懂** |

### 🔴 洗稿走不通，有一个很硬的理由

不是道德问题，是**结构问题**：

> 看到一个爆款罗列了 4 个观点，你想换个说法重讲。
> **内核不动的话，你凑不出第二个既站得住、又和他完全不同、还讲得通的观点，更别说四个。**
> 强行改出来的，必然是空洞的废话。

**观点的数量是被理论内核锁死的。** 想要不同的观点，只能换一个更深的内核——
而换内核，就必须回到「你自己想搞懂什么」这个起点。

🔴 **为什么这一步不能省**：常识缺口法的第 ③ 步要「你自己的路径」。
**如果起点是刷别人的内容，你根本没有路径可讲**——你走的是他的路，只是换了口音。
下游的每一步都会因此变虚：找出来的缺口是别人指过的，配的理论是临时找来撑场面的。

**判据**：动笔前答一句 —— **「我是为了解决什么问题去搞懂这件事的？」**
答不出来，说明你是从别人的内容出发的。**回去找一个你自己真的卡住过的问题。**

⚠️ 这条和〈亮路径三幕〉是同一件事的两头：
**那边说「路径是唯一抄不走的东西」，这边说「路径从哪一天开始的」。**

## ⓪-2 🔴🔴 命题必须是解困型，不能是增益型（2026-08-25 用户定，实测代价一整版稿）

**这一条排在五步之前，因为五步全做对了，命题选错照样是废稿。**

| | **增益型**（❌） | **解困型**（✅） |
|---|---|---|
| 命题长什么样 | 「X 有一个你没想到的好处」 | 「你现在卡在 Y，这里有个解法」 |
| 观众听完 | 「哦，还有这个好处」 | **「这正是我卡着的地方」** |
| 观众的状态 | 他本来不缺这个 | **他本来就在焦虑这个** |
| 结果 | 叙事再好也是平的 | 不用起伏就已经抓人 |

### 🔴 实测（2026-08-25，整版作废）

一条讲写作的稿，命题是「**写作能让别人在你不在场时认识你**」——增益型。
被判「**叙事太平，一点击中都没有**」。

同一天对照的另一条同样讲写作的对标内容，命题是「**你想创业但没本钱、怕一次失败就出局，
这里有个几乎零成本、成功率极高的方法**」——解困型。**同一个主题，命中率完全不同。**

> **⇒ 平不平不是句子的事，是命题选错了。**
> **改句子救不了增益型命题，只能重选命题。**

### 判据（动笔前必须答，答不出不许往下写）

```
① 这条内容解决的，是观众此刻正在焦虑的哪一件事？
② 那件事他会不会主动去搜、去问、去跟朋友抱怨？
③ 如果他从来没为这件事烦过，这条对他就是「知道了」，不是「太好了」。
```

**②答不出来 = 你选的是增益型。回去换。**

### 怎么从增益型改回解困型

**不换概念，换入口。** 那个概念本身通常是对的，错的是你从哪扇门把观众领进来。

```
增益入口：写作能让人认识你        →  谁在焦虑这个？很少人
解困入口：你加了三百个微信，
          真要办事一个都开不了口  →  ★ 这是普遍焦虑，且常识是错的
          （常识：人脉＝认识多少人 → 所以去混圈子、去加人）
```

🔴 **判据**：入口必须是**观众会拿去跟朋友抱怨的那句话**。
「我没人脉」「我没本钱」「我不知道从哪开始」——这些是抱怨。
「我不知道写作还有这个好处」——**没有人这样抱怨。**

⚠️ 与 §5.32 的关系：那条说落点要锚你的判断方式。**本条只管入口，不改落点。**
**入口解困，落点仍然是你的判断。**

## 五步（顺序不能换）

```
① 找一个大众常识        市面上人人都默认成立的那句话
② 找它解释不了的现象     一个具体的、常识圆不回来的 case
③ 配一个深厚的理论       我的认知系统 / 我的经验 / 我见过的案例 + 经典背书
④ 讲成反常识            用理论说清常识偏在哪 → 不明觉厉 + 观众有新收获
⑤ 往上引申一个大切口     ★ 标题和前 5 秒从这里来
```

### ① 找大众常识

不是找「别人讲过的观点」，是找**没人觉得需要论证的那句话**。

判据：**说出来对方会点头，觉得你在说废话。** 那就对了——废话才是常识。

- 「流量为王」「先有用户再谈产品」「做内容要日更」「精准获客最重要」
- ⚠️ 越是行业里人人挂在嘴边的，越值钱

🔴 **不要挑一个稻草人。** 你编一个没人真这么想的说法去打，观众看得出来。
→ 去评论区、去真实对话里找，别在脑子里造。（同 `选题三路.md` 第一路的第一条纪律）

### ★★ ①b 认知落点表：不光找「大众信什么」，要找「大众现在拿什么在做」（2026-08-26 加）

> 🟢 詹明明 2026-08-26 定：**这一层就是「多数人的认知落点」，它是 ① 的产出程序，不是另一个步骤。**

**① 只回答「大众信什么」（信念），本节要求再往前走一格，回答「大众现在拿什么在做」（解法）。**

```
信念   人脉 ＝ 认识多少人           ← 抽象，没有画面
解法   所以去混圈子、去加人、去换名片 ← ★ 具体，有画面，而且可以当场说它为什么不管用
```

🔴 **为什么这一格必须走**（三条，每条都对应一个已有规则）：

| | 走了这一格才拿得到 | 对应规则 |
|---|---|---|
| 1 | **归因反转的那个 X** —— X 必须是**机制／习惯／形式**，而「错误解法」天生就是一个形式，不是一群人 | 归因反转规则 |
| 2 | **② 的现象** —— 「他用这个解法，结果没用」本身就是常识圆不回来的那件事，不用另外去找 | 本文 ② |
| 3 | **`概念型口播 ②` 替观众说出他的答案** —— 那一拍要说的正是这个解法，而且要说得**像样** | `概念型口播 ②` |

#### 强制产出：枚举 6–10 行，不许只写一行

**不许在脑子里挑一个就开写。** 先铺开，再筛。

| 谁 | 什么时候撞上这事 | ★ 他嘴里怎么说的 | ★ 他现在怎么对付、哪儿不灵 | 听完我的判断他会改做什么 | 改了之后看得见的变化 |
|---|---|---|---|---|---|
| | | | | | |

**每一列的判据：**

- **具体人群**：不是「大家」。是「刚做完产品的人」「在公司写方案的人」「带团队的老板」。
  ⚠️ 但受「先散后聚」约束，最终要能收到一个共性，不能只锁一个职业
- **触发场景**：能想象出来的那一刻（「翻完通讯录那一刻」「方案交上去没回音那一刻」）
- ★ **当事人的原话**：**他会拿去跟朋友抱怨的那句话**，不是你对他的概括。
  判据同 `⓪-2`：**「我没人脉」是抱怨；「我不知道写作还有这个好处」没有人这样抱怨**
- ★ **现有解法及局限**：他现在真的在做的那个动作 + 它为什么不管用。
  🔴 **局限必须是机制层的**（「加人不产生信任，因为见面拿不到结论性信息」），
  **不能是人层的**（「因为那些人都很功利」）—— 后者直接违反归因反转规则
- **行动变化**：用了我的判断之后，他今天做的事有什么不同
- **可观察结果**：他自己当天能看见的东西（同 事实型，不是判断型）

#### 六项打分，筛出 3–5 个

| 维度 | 问什么 |
|---|---|
| **频率** | 多少人真的碰到 |
| **痛感** | 他会不会主动去搜、去问、去抱怨（`⓪-2` 判据②） |
| **解释力** | 我的判断能不能真的解释它，而不是贴个标签 |
| **可执行** | 行动变化落不落得到动作层 |
| **结果可感知** | 他当天看不看得见 |
| **独特性** | 这个说法他在别处听没听过（= `④` 的「非共识」那一半） |

🔴 **人群铺得越广、问题越说不清的方向，排序往后放。** 同 ① 的判据：
**宁可具体到只有一部分人，也不要概括到所有人。**

#### 素材从哪来（优先级不变）

沿用本文 ② 的来源优先级：**现场原话 > 群里提问 > 你自己的 > 对标标题**。
⚠️ **「现有解法」这一列尤其不能在脑子里造** —— 你以为大家在做的事，和大家真在做的事经常不是一回事。
去评论区、去真实对话、去看他们实际发的内容。

#### 🔴 实测教训（N20，2026-08-25 → 08-26）

N20 写了三版才发现病灶，**根因就是跳过了这一格**：

| | 只做了 ① | 补上 ①b 之后 |
|---|---|---|
| 拿到的 | 常识：想清楚了再动手 | 常识 + **解法：所以我回去再想想** |
| 归因反转的 X | 🔴 **没有**，只能写成「你的结论是错的」= 指控观众 | ✅ **「想」这个动作本身** —— 机制，不是人 |
| `概念型口播 ②` | 🔴 漏拍 | ✅ 「你当时的第一反应大概是，我回去再想想」 |

**⇒ 缺了「现有解法」这一列，归因反转就无处可挂，稿子必然滑向指控观众。**

### ② 找它解释不了的现象

**这一步是整套方法的支点。** 一个常识如果没有解释不了的地方，它就是对的，别硬打。

问：**顺着这个常识往下推，哪一个真实发生的事情它圆不回来？**

- 「流量为王」→ 那为什么一堆有流量的账号卖不动东西
- 「先有用户再谈产品」→ 那为什么有人手上有资源有人脉，还是拿不出能交付的东西

⚠️ **现象必须具体到能看见**：一个数字、一个场景、一件真发生的事。
「很多人都这样」不是现象，是又一句常识。

### 🔴🔴 ② 的现象不许是「为了打那句常识而构造出来的巧合场景」（2026-08-27 詹明明 定，实测代价：选题层整格返工）

> 🟢 **詹明明 原话（未改写）**：
> 「**现象不是复述的一字不差还做错，而是很多时候双方的信息没有对齐，并不存在复述问题，
> 可能只是真的理解问题，或者是对彼此的了解熟悉的问题，说到底还是没有共识。**」

**踩到的坑长这样**：常识是「出岔子总有一方没说清或没听懂」。
为了把这句常识证伪得干净利落，我构造了一个现象 ——
**「他当着你的面复述了一遍，一字不差，做出来还是错的」。**

它逻辑上完美：信息完整传到了，事还是错的，常识当场圆不回来。
🔴 **但现实里几乎没人这么干。** 大多数场合根本不存在「让对方复述」这个动作。
**我造的是一个刚好能被我的理论解释的场景，不是一个真发生的场景。**

| | ❌ 构造出来的现象 | ✅ 真实的现象 |
|---|---|---|
| 长什么样 | 精确、干净、刚好证伪那句常识 | **钝**。经常连「出错的那一刻」都很模糊 |
| 从哪来 | 从理论倒推出来的 | 从他上个月真碰到的事里来的 |
| 观众反应 | 「嗯，有道理」 | **「对，我就是这样」** |
| 例（例稿 A） | 他复述得一字不差，做出来还是错 | **压根就没有对齐这一步**，两边各自以为懂了就开工了 |

#### 🔴 判据（动笔前答一句，答不出就换）

> **这个现象，是我为了打那句常识而设计出来的，还是他上个月真的碰到过的？**

**设计出来的 = 换。** 补充检查：
- 现象里有没有一个「刚好」（刚好复述了 / 刚好记录了 / 刚好双方都在场）？**有「刚好」就是构造的**
- 把理论拿掉，这个场景还成立吗？只在理论里成立 = 构造的

⚠️ **与本节原有的「现象必须具体到能看见」不冲突，但排在它前面**：
**先真，再具体。** 一个具体但没发生过的场景，比一个模糊但真实的场景更危险 ——
它更像样，所以更不容易被发现。

### ★ 例子从哪来：网上人人刷到过的现象，正反各有一种用法（2026-08-25 用户定）

**② 的「解释不了的现象」和 ④ 的论据，优先从「网上常见、观众自己刷到过」的东西里取。**
不从自己脑子里造，也不只靠私人案例——**私人案例观众验证不了，公共现象他一秒就认。**

两种用法，**方向相反，都要有**：

| | 拿它干什么 | 放在第几步 | 例 |
|---|---|---|---|
| **正面例子** | **当论据** —— 证明这个机制真的在起作用 | ④ | 装修师傅的作品相册、店门口排的队 |
| **反面例子** | **当现象** —— 这是「那个错误常识」造成的后果，然后**用理论当场戳破它** | ② | 满屏「怎么跟大佬搭上话」的话术教程、几十万粉丝卖不动东西 |

🔴 **反面例子的用法有一个必须守住的顺序**：
**先把那个现象说得像样**（说到观众心里想「对，我就是这么以为的」），**再用理论戳。**
先戳后说 = 打稻草人，观众看得出来。⇒ 同 `概念型口播` 第②拍。

⚠️ **公共现象也要守卖真**：说「满屏都是这种教程」可以（人人可自查），
说「某某账号几十万粉卖不动」不行（那是具体指控，得有证据且会点到人）。
**判据：这句话观众能不能自己打开手机验证？** 能 = 可用；不能 = 要么去核，要么不说。

### ③ 配一个深厚的理论

**理论有两个来源，都要，而且分工不同：**

| 来源 | 提供什么 | 例 |
|---|---|---|
| **你自己的**（认知系统 / 经验 / 见过的案例） | **路径**——唯一抄不走的部分 | 「我踩过 N 次之后发现…」 |
| **经典背书**（书 / 文献 / 经典理论概念） | **分量**——让它从「你的看法」变成「有根的判断」 | 一本 ≥20 年的海外经典 |

🔴 **两者缺一不可**：
- 只有你自己的 → 观众读作「一家之言」
- 只有经典背书 → 那是转述，谁都能讲，**又回到抄结论**

⚠️ **引用照旧走 E1–E5 纪律**（见 `config.paths.feedback_rules`）：
默认每条 1–2 本、海外、出版 ≥20 年、**必须 grep 过原文**、名字念不顺的只用观点不报名、
引用是给**已有判断**找根，不是引出你没说过的东西。

### ④ 讲成反常识

用理论说清**那个常识偏在哪**，不是说它全错。

目标是三样同时发生：

| 要的效果 | 判据 |
|---|---|
| **反常识** | 观众心里冒出「诶，我一直以为不是这样」 |
| **不明觉厉** | 他答不出你这个说法是从哪本书哪套体系来的，但他信 |
| **有新收获** | 他能带走一句以前没有的判断，不只是一个情绪 |

🔴 **不要为了反而反。** ②里那个「解释不了的现象」就是安全绳：
**现象撑不住的反常识，就是抬杠。**

### ★ 一个更准的叫法：正确的非共识

「反常识」这个词漏了一半。完整的要求是两件事同时成立：

```
非共识  ——  跟大部分人以为的不一样
  正确  ——  而且它是对的
```

**少了「正确」就是抬杠，少了「非共识」就是废话。**
判据顺序是先验「正确」再验「非共识」——**因为抬杠也能拿到流量，那是最容易走错的一步。**

### ★★★ 落点句：④ 必须能写成一句**第一人称的处境话**（2026-08-26 加）

> **它补的洞**：④ 原来只有**效果判据**（反常识 / 不明觉厉 / 有新收获），**没有格式**。
> 没有格式，④ 就会被写成一个**命题**，而命题不产生共鸣 —— 观众要在脑子里把它翻译成自己的处境，
> 那一步他不会做。

#### 🔴 判据：把 ④ 换成第一人称，还说得通吗

```
命题（❌ 会写成这样）   议程设置：媒体报道什么，公众就以为什么重要
处境（✅ 要这样）        我的注意力每天都被外界安排。
                        我把反复出现的事，当成了眼下最重要的事，
                        却没有精力处理与自己有关的问题。
```

**同一个理论，右边那版观众一秒对号入座，左边那版他要先当一次翻译。**

#### 三段结构（缺一段就会绕）

| 段 | 写什么 | 样例（议程设置） |
|---|---|---|
| **① 机制落在我身上** | 用最普通的话说清这件事在「我」身上是什么样 | 我的注意力每天都被外界安排 |
| **② 我因此做错了什么** | ★ **必须是一个动作**，不是一种状态 | 我把反复出现的事，当成了眼下最重要的事 |
| **③ 代价** | 我因此**失去**了什么。⚠️ 是失去，不是「不够好」 | 却没有精力处理与自己有关的问题 |

🔴 **② 最容易漏，也最承重。** 只有 ①③ 就变成了一句感慨；
**有了 ② 才有「我原来一直在做这件蠢事」的那一下。**

### ★★★ ① 要写两版：认知版推理用，情绪版对外用（2026-08-26 晚三定，詹明明 拍板）

> **这一节是本文档共鸣的全部来源，比上面三段更承重。**

三段写完，**共鸣还没有** —— 因为三段全是**认知描述**。
观众不会因为一个认知描述有共鸣，**他只会因为一个他此刻正在承受的东西有共鸣。**

⇒ **把 ① 重写一遍，换成情绪词。标题从这一版来；但它不当第一句 —— 第一句要给观众「有解」，情绪版挪到中段当替观众说的那一句。**（后来裁定：第一句先给有解不给你惨，情绪版放中段；标题仍从情绪版长出来。）

| | 认知版（内部推理用） | ★ **情绪版（中段代言句 / 标题来源）** |
|---|---|---|
| **议程设置** | 我的注意力每天都被外界安排 | **我每天焦虑什么，不是我自己决定的** |

**看清楚这两句说的是同一件事**：注意力 → **焦虑**，被外界安排 → **不是我自己决定的**。
**没有新增任何信息，只换了一套词。而共鸣全在换词这一步。**

#### 🔴 判据一 · 语义跃迁：认知词必须被换掉

```
认知词   注意力 · 想 · 判断 · 信息 · 决策 · 逻辑
             ↓ 必须换成
情绪词   焦虑 · 没底 · 卡着 · 睡不着 · 定不下来 · 慌
```

**★ 硬检查**：情绪版里如果还是同一批认知词，**说明你只是换了个说法，没有换层。**

#### 🔴🔴 判据二 · 时效性：必须是他**此刻正在承受**的（2026-08-26 詹明明 定）

> 🟢 **詹明明 原话**：「**此刻正在承受的，优先级肯定是远高于回想起来难受的。
> 痛点一定要痛，而且要有时效性。**」

| | 例 | 判定 |
|---|---|---|
| ✅ **此刻正在承受** | 焦虑 · 心里没底 · 卡着 · 定不下来 · 睡不着 · 不敢开口 | **他现在就在这个状态里** |
| ❌ **回想起来才难受** | 后悔 · 走过的弯路 · 交过的学费 · 浪费的那几年 | **痛感隔了一层，要他回望才有** |

🔴 **判据一句话**：
> **这句话说的事，他是「现在正在经历」，还是「想起来会难受」？**
> 现在正在经历 = 过。想起来才难受 = **不过，回去换。**

⚠️ **实测代价（N20，2026-08-26）**：第一轮拟的三个情绪词（后悔 / 弯路 / 学费）**全是回望型**，
被 詹明明 当场判「**不是最疼或者最命中的感觉**」。**三个候选一起作废。**

#### 🔴 判据三 · 翻转

固定形状「**你以为是 A，其实是 B**」，B 是他没想到的来源，且**答案那一半藏起来**。

> 我每天焦虑什么，**不是我自己决定的** ← 那是谁决定的？（缺口留这儿）

#### 🔴 判据四 · 外行复述

念给一个不懂这行的人听：
- 他说「有道理」→ ❌ 不算过
- 他复述的是**机制**（「哦，就是注意力被媒体带走」）→ ⚠️ 只算过了认知版
- 他复述的是**那个情绪**（「就是我天天焦虑的事其实不是我想焦虑的」）→ ✅ **过**

#### 标题 = ① 的情绪版换个人称

```
① 认知版   我的注意力每天都被外界安排
                ↓ ★ 换情绪词（这一步是共鸣的全部来源）
① 情绪版   我每天焦虑什么，不是我自己决定的
                ↓ 只换人称
标题       你每天焦虑什么，可能不是你自己决定的
```

> 🔴 **2026-08-26 晚三两次改正，记在这里防重犯：**
> **改正一**（原写法）：「从三段里挑缺口最大的那一段（通常是①）→ 换第二人称」——
> **那只是语法操作，漏了语义跃迁。** 产出《你越想越对，不是因为你想对了》，
> 「越想越对」是认知现象，共鸣不起来。
> **改正二**（我当天的第一次修补）：把情绪版写成「第四段」，当成三段之后**再加一句**——
> **也不对。詹明明 拍板：它是 ① 的情绪版重写，不是新增一段。**
> 同一句话，换一套词，**不新增任何信息**。

🔴 **情绪版写对了，标题基本就是它换个人称。换完觉得不够劲，问题在情绪版，不在标题。**

#### 🔴 自检五条

- [ ] 落点句里**没有任何术语**（可证伪 / 议程设置 / 默会知识 —— 一个都不许出现）
- [ ] 三段齐了，尤其 **② 是一个动作**
- [ ] ★ **① 有情绪版**，且里面出现了认知版里没有的情绪词（语义跃迁）
- [ ] ★★ **那个情绪是他此刻正在承受的**，不是回想起来才难受的
- [ ] 念给外行听，**他复述回来的是那个情绪，不是那个机制**

### 🔴 配套陷阱：不要变成工具号

**具体的工具、案例、产品，只是承载观点的切口，不是内容本身。**

> 工具只是例子，**你真正在讲的是那个借工具才说得清的判断**。

三个后果，按严重程度排：

| | 只讲工具 | 用工具讲观点 |
|---|---|---|
| 人群 | 只有用这个工具的人 | **所有有这个问题的人** |
| 保质期 | 工具一换就作废 | 观点还在 |
| 账号 | **变成工具号**——工具过气，账号跟着过气 | 观点累积成认知资产 |

**判据**：把稿里那个工具换成另一个同类工具，**这条内容还成立吗**？
不成立 = 你在讲工具。
⚠️ **实测踩过**：一条讲「暗文」的稿，落点落在「AI 知识库为什么不好用」上，
被判「切口不够大，局限在 AI 了」。改法是把 AI 降成并列例子之一
（带新人 / 找外包 / 请代运营 / 用 AI），**观点不变，人群翻了四倍**。

### 配套：一个例子被质疑以偏概全，解法是建合集

单条内容只能拿一个例子讲，必然以偏概全。**不要在单条里补例子——那会稀释密度。**

> **多个「以偏概全」加在一起，就全了。**

⇒ 同一个观点用不同切口讲多条，**成合集**。合集同时解决三件事：
反驳（覆盖面）、留存（有理由持续看）、产品化（合集本身就是可交付物）。

🔴 **但合集的轴不是话题，是你要植入的那一个判断** —— 这一层比「多讲几条」重要得多，
**单独写在 `议程与合集.md`**。按话题建的合集（「拍摄技巧」「文案撰写」「工具推荐」）
补不上以偏概全，因为那些条目彼此孤立。

### ⑤ 往上引申一个大切口

**到这一步才起标题。** 把④得到的那个判断往上抬一层，抬到泛人群的处境上。

```
深的判断（小众）  →  往上抬一层  →  大切口（泛人群）
```

- 判断：产品不承担说服，所有说服都得靠投放买回来
- 切口：**别加功能**

**大切口的判据（四条全过才算）：**
- [ ] 不懂这行的人也知道你在说什么
- [ ] 它是从④**结果句**长出来的，**不是从别的爆款上摘的，也不是从①换人称换出来的**
- [ ] ★ **它落在观众每天在承受的东西上**（焦虑 / 后悔 / 白忙 / 一直没开始），
      **不是落在一个认知现象上**（越想越对 / 注意力被分配 / 信息过载）
- [ ] 把它单独拿出来，仍然有一个缺口（观众不知道你要说什么，但想知道）

🔴 **第三条是 2026-08-26 晚三补的，它是最容易漏的一条。**
认知现象也能写得很漂亮，但**漂亮不等于有人疼**。

⚠️ 抬**一层**就够，抬两层会到「人生哲理」，那是空的。
（同 作者方法论 §5.62：可以往上抬一点，但只抬一句）

### ★★★ 前 5 秒的两件必需品：共鸣 + 缺口（2026-08-26 加）

> **来源**：詹明明 2026-08-26 指出，两个不同来源的开场是同一个形状。

```
只有共鸣没缺口   →  他点头，但没有留下来的理由        ← ★ 最常见的病
只有缺口没共鸣   →  他好奇一下，然后想「跟我没关系」
两个都有        →  「这说的就是我」+「后面那半句是什么」
```

**两个实证样例，形状一致：**

| 来源 | 共鸣（大众常碰到的） | 缺口（当场打开、不当场兑现） |
|---|---|---|
| 某条讲创业的爆款（自造示意） | 创业成本高、成功率低 —— 人人都怕一次失败就出局 | 「有一种做法几乎不花钱，而且很少失败」<br>★ **不说是什么** |


🔴 **判据（两条都要过）**：

- [ ] **共鸣**：这句话说的事，观众**这个月碰到过**吗？（不是「能理解」，是「碰到过」）
- [ ] **缺口**：读完这一句，他心里**有没有一个还没被回答的问句**？写出来那个问句是什么

⚠️ **纯铺垫不算共鸣。**「你有一件想了很久的事」是铺垫 —— 它没说出任何他会点头的**判断或反常**。
**共鸣要落在一个他会说「对，就是这样」的具体处境上。**

### 🔴 如果开场是**指令句**，缺口那一半要换成收益

**「强烈建议你 XXX」这种句式本身没错，错在后面不跟东西。**
⇒ **指令 → 紧跟收益 → 再回到指令。** 收益句夹在中间，把说教味吸收掉。
🔴 **判据：这句收益是我承诺给他的，还是他本来就想要的？** 我承诺的 = 撞卖真红线（裁定 #16）。
📄 完整判据见 `规则总表 D20`。

🔵 **为什么这一条值得单列**：N16 实测 **2→5 秒三秒掉 24.9pp（8.3pp/秒），
而 5 秒之后 178 秒共掉 40.7pp（0.23pp/秒）—— 差 36 倍。**
**前 5 秒是全条唯一的 36 倍杠杆位，不许拿它做铺垫。**

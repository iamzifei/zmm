# 测试稿 01 · 答案（只给评分者）

## 必须做到（5）

| # | 要求 |
|---|---|
| T1 | 判定「35 岁转行」是话题不是题，先写出目标观众的默认答案（例如「转行风险太大 / 不转就废了」之一） |
| T2 | 拉力来源三选一并说清（多半是「两个时间尺度打架」：前两年腰斩 vs 第三年回本；或「有人在付账但不在场」：家人 / 房贷） |
| T3 | 替对面写一句讲得通的话（「不转」那一方的合理理由），且对面不是目标观众本人 |
| T4 | 压成一句会有人反驳的话，并写出谁会反驳、会说什么 |
| T5 | 给出三个版本（稳 / 带刺 / 押注），并注明推出来的题仍要回模式 B 过供需 |

## 不许出现（3）

| # | 要求 |
|---|---|
| N1 | 不出现「六型冲突」「四层争点」之类的分类表 |
| N2 | 不把「不转行的人」或「35 岁的中层」立成靶子 / 敌人 |
| N3 | 不用「利益冲突」「认知差」这类抽象词收尾，第五问必须是画面句 |

## 评分

T1–T5 各 1 分；N 违反各扣 1 分。满分 5，通过线 4 且 N 不扣。

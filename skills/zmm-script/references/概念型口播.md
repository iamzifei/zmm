# 概念型口播：让人带走一把尺子，不是带走一个观点

> 管的是**正文结构**。选题和前 15 秒归 `zmm-topic/references/常识缺口法.md`，两者是上下游：
> **常识缺口法产出「要讲哪个概念」，本文管「怎么把它讲成知识」。**

---

## 病症：论证型稿子

用户 2026-08-24 的原话诊断（针对两条已写好的稿）：

> **「太平淡了，没有什么获得感，就是听我聊了一个观点而已，而不是一个知识的感觉。」**

这不是措辞问题，是结构问题。两种结构的差别：

| | **论证型**（默认会滑向这个） | **概念型** |
|---|---|---|
| 稿子在干什么 | 论证「我这个判断成立」 | 教会一个概念，然后**当场用它量东西** |
| 概念的角色 | **标签**——用来概括我已经说过的话 | **工具**——用来解释我还没说的事 |
| 场景数量 | 1 个（就是我要论证的那件事） | **≥2 个，且第二个必须跨出本行业** |
| 观众带走 | 「我同意他」 | 「我手里多了一把尺子」 |
| 结尾 | 一句金句 | **一道作业** |

### 🔴 唯一的判据

> **把这个概念交给观众，他能不能拿去解释一件你没提过的事？**

不能 = 你给的是观点，不是知识。**这条判据写完就能当场测，不用等数据。**

## 结构（七拍）

```
① 一个具体场景 + 一个问题     观众心里立刻会有一个答案
② 替他把那个答案说出来        ★ 最容易漏的一拍
③ 判定：不对 / 不止于此
④ 机制一句话：为什么错         概念在这里第一次出现
⑤ 给它命名
⑥ ★★ 用它解释第二个场景       —— 而且要跨出本行业
⑦ 留一个他能立刻用的动作
```

### ② 替观众说出他的答案 —— 这一拍决定成败

不是「有些人会觉得……」这种虚指，是**把那个错误答案完整、认真、不带嘲讽地说一遍**，
说到观众心里想「对，我就是这么想的」。

🔴 **说得越像样，后面的推翻才越有价值。** 敷衍地立一个稻草人，观众看得出来。

⚠️ 与 `feedback_rules` H14（指控第三方不指控读者）配合：
说的是**「大家都会这么算」**，不是「你错了」。

### ④⑤ 概念必须是工具，不能是标签

判断方法很简单：

> **这个概念能不能用来算/量一件我还没说的事？**

- ❌ 标签：用来概括本条内容的那句话——它只描述你刚讲完的东西
- ✅ 工具：一把可以拿走的尺子——一个能拿去算别的账的算法，一个能拿去看别人东西的判据

**同一个词可以是标签也可以是工具，区别在于你有没有当场用它量第二样东西。**

### 🔴🔴 ⑤ 命名时，优先重新定义一个观众已经在用的词，不要造需要先教会他的新比喻（2026-08-27 詹明明 定，实测代价：整版重写）

> 🟢 **詹明明 原话（未改写）**：「**不要用密码本这个概念，听上去很奇怪，就用共识这个概念。**」

**踩到的坑**：例稿 A 要讲「两个人对不齐，是因为那套规则没被写下来」。
我给它起名叫**「密码本」** —— 比喻本身是准的（香农那套通信模型里两端必须共用规则），
**但观众第一反应是「加密、保密」，跟要说的意思正相反。**

| | ❌ 造一个新比喻 | ✅ 重新定义一个旧词 |
|---|---|---|
| 例（例稿 A） | 密码本 | **共识** |
| 观众第一反应 | 跟你要说的意思**可能正相反** | 就是**那句大众常识本身** |
| 要花多少行去锚定 | **四行**（例稿 A v1 用了 25–28 行） | **一次排除法**（例稿 A v2 用了 13–16 行，含现象） |
| ★ 意外收益 | 无 | 🔥 **被排除掉的那个错误理解，本身就是 `常识缺口法 ②` 要的现象** ——<br>「大部分人说的共识就是聊完都点了头。**但你那些返工，哪一次不是聊完都点过头的**」<br>⇒ **概念和现象长在一起，不用另外去找** |

#### 🔴 判据（命名时问两句）

1. **这个词观众第一次听到，会不会先想到另一个意思？** 会 = 换掉
2. **有没有一个他已经在用、但从来没被定义清楚的词，说的正是这件事？** 有 = 用它

⚠️ **代价必须知道**：熟词有**沦为标签**的风险（本文 ④⑤ 的核心禁忌）——
它太熟，观众听完可能不觉得手里多了一把尺子。

🔴 **破法是强制的，不是可选的**：
- **必须先走排除法**：先排除大众那个理解，再给一个能当场量东西的正面定义
- **必须在 ⑥ 拍当场用它量两样你没提过的东西**（例稿 A 用咖啡店和看病）
- ⚠️ **口播时那段排除法不能说快。** 说快了观众会拿他自己那个理解去听剩下的全部内容，
  整条退回「又一个讲 X 的」。例稿 A 已把这条写进 📣 清单的「本版命门」

### ⑥ 第二个场景必须跨行业 —— 「获得感」全部来自这一拍

**这是本文最重要的一条。**

观众不会因为你把一件事讲透而觉得学到了东西。他觉得学到了东西，是因为
**他看见同一把尺子量了两样看起来毫不相干的东西，还都量准了。**
那一刻他才相信这把尺子是真的，并且开始在心里量第三样。

跨行业的三种拿法，按效果排序：

| | 做法 | 为什么强 |
|---|---|---|
| **1. 让观众在自己身上量** | 给一个人人经历过的处境，问「你当时什么感觉」 | 他不是在听案例，他在验证 |
| **2. 换一个完全不同的行业** | 同一个机制在餐饮 / 招聘 / 租房 / 看病里长什么样 | 证明尺子通用 |
| **3. 反向量一次** | 用它解释「为什么有的人不需要做这件事」 | 证明尺子有刻度，不是万能咒 |

🔴 **写对照概念时，检查落点有没有漏掉另一半（2026-08-24 实测）。**
一次实测：稿子写「立体是因为里面**有暗文**」，他实拍说成「因为里面**有明文，也有暗文**」——
**他是对的。** 立体不是只有暗文，是两者交织。
⇒ 定义了 A/B 一对概念之后，**落点句要回头核一遍：说的是 B 一个，还是 A 和 B 一起？**

🔴 **不要用同行业的第二个例子。** 那不叫第二个场景，那叫补充论据，观众感觉不到尺子。

### 🔴🔴 实测警告：并列例子在实拍中会塌缩（2026-08-24）

**用「A / B / C / AI」这样的并列来避免工具号，是写在纸上成立、说出口失效的。**

一次实测：稿子刻意写「你带新人，你找外包，你请代运营，你用 AI」四例并列，
**播出版两处都只剩了 AI** —— 那一版最核心的改动（去工具号）在实拍中完全失效。

⇒ **靠并列承担结构时，必须做两件事之一：**
1. **让并列成为句子的语法结构**：「不管是……还是……，都……」——语法逼着你说完
2. **在拍摄处理表里单列一行**，标「几个连着念，一个都不能少」

**写在正文里靠自觉，保不住。**

⚠️ **跨行业例子不得编数字。** 用人人可自查的日常处境（G2：不能编）。
说得出机制就够——**数据留给本行业那个场景用。**

### ⑦ 作业，不是金句

**结尾给一个他今晚就能做完、且能产出一个属于他自己的答案的动作。**

判据（同 `feedback_rules` H3/H4）：
- 门槛低到荒谬 + 有触发器（「今晚」「下一次你……的时候」）
- 反馈在**动作层**不在结果层（不是「他觉得好不好」，是「他答不答得上来」）
- ★ **做完之后他手上有一个数或一个答案**，那个东西是他的，不是你的

## ★★★ 光「说清楚」是及格线，不是内容（2026-08-25 用户定）

> **平铺直叙地把一件事讲清楚，四种情绪价值一个都不占。**

| | 怎么产生 | 在七拍的哪一拍 |
|---|---|---|
| **获得感** | 给一把能量别的东西的尺子 | ⑥ |
| **优越感** | 让他看懂一件周围人还没看懂的事 —— **「原来那些人做的是白功」** | ③④ |
| **独特感** | 这个说法他在别处没听过（正确的非共识） | ④ |
| **满足感** | 缺口被兑现 | 全程，见下 |

### 一 · 🔴 缺口不是一次性的，要铺满全程

**这是「叙事太平」的直接病因**（2026-08-25 实测，一整版稿因此作废）。

> **完整的节奏是：给一点，留一点。只给会平，只留会烦。**（`作者方法论 §5.58 补`）

**出稿必须做的检查**：把稿子按段落切开，标出每个缺口的位置。

| 症状 | 处理 |
|---|---|
| 开头密集，中段空一大片 | 🔴 **最常见**。中段**每 30–45 秒补一个缺口** |
| 通篇都是钩子 | ⚠️ 显得油。**缺口之间必须有兑现**（2026-09-01 已改成可执行判据，见下） |
| 路标当钩子用 | 🔴 **「第一件事/第二件事」是路标不是钩子**。路标告诉你还剩多少，钩子让你想知道下一句 |
| ★ **每个缺口都是另起的**（2026-09-01 加） | 🔴 **这是「像一份清单」的直接病因**。缺口之间要**接力**：这一段的答案自己长出下一个问句 |

四种手法（公式都是「给 X 不给 Y」）：给结果不给过程 · 给矛盾不给解释 · 给问题不给答案 · 给反常不给理由。

#### ★ 上面这张表只管「哪儿缺」，2026-09-01 补上了「怎么连」

> 外部素材《多巴胺阶梯叙事法》去重后**只剩这一件是本库没有的**：
> **缺口之间的关系**。此前所有规则（节奏规则 / 本节）管的都是**节拍**（每 30–45 秒来一个），
> 没有任何一条管**连法**。

| | 判据 | 权威 |
|---|---|---|
| **接力不并列** | 把每段的答案抄出来：**这个答案本身有没有制造出下一个问句**？<br>谁先谁后都行 = 清单；**B 只有知道 A 之后才问得出来 = 阶梯** | `规则总表 C10` |
| **收支平衡** | 每开一个缺口，**在下一个开启之前**要有一行兑现它；**一次只还一层**<br>（一次还清 = 后面无梯可上，剩下的全是复述） | `规则总表 C11` |
| **段尾不收在句号上** | 把每段最后一句单独拎出来：**它是合上了，还是把人推向下一段**？<br>🔴 **但「但这里有一个反转」这类现成句式禁用** —— 撞 `语言风格档案` 禁区「强行金句」 | `规则总表 C12` |

🔴 **「拉高代价」不在这三条里** —— 它和「第一句给有解不给你惨」「零说教」冲突，只能用「他已经在承受的代价」，
且**一律 5 秒之后**。完整裁定：`文案框架-总入口 §3 #18`（本库「筹码」是另一个概念，**不许借这个词**）。

🔴 **⑤段内部不许为了悬念重排推理顺序**。阶梯只在六段容器层调节缺口开合 —— 裁定 §3 #19。

### 二 · ★ 预演观众的反应（2026-08-25 用户裁定：**不算擦边，可用**）

不说「这个方法很厉害」，**把观众听完之后的那句内心话提前演出来**。

```
承诺结果         「你会赚到钱」               🔴 违反卖真
承诺信息         「我告诉你一个方法」          🟡 平淡
承诺一个内心 OS   「你会觉得，原来是这么回事」   🟢 兑现成本低，不违反任何红线
```

判据三条：承诺的是**他自己会产生的感受**；**没有量化任何结果**；**正文里真的会发生**。

### 三 · 🔴 观点鲜明 > 观点中庸

> **即使有人喜欢有人不喜欢、会产生争论 —— 流量和人群就是在争论里获得的。**

判断说死，不骑墙，不在每个判断后面挂「当然也要看情况」。

**但「鲜明」不等于「爆论」**：
```
✅ 鲜明   判断明确、敢得罪一部分人   —— 依据充分，只是立场硬
🔴 爆论   把没依据的说死、承诺结果   —— G 组红线
```
**判据：这句话被人反驳时，我拿得出依据吗？** 拿得出＝鲜明；拿不出＝爆论，删掉。

### ★ 还要找一个「纠偏理论」

主理论负责解释**为什么成立**，还要至少找一个方向说明**什么时候失效**。

⇒ 那句话就是 `作者方法论 §5.0` 要求的**边界**（「每给出一个方向，配一条它什么情况下不适用」）。
**此前边界一直靠拍脑袋想，现在它有来源了。**

⚠️ 纠偏理论**不必进成稿**（受「一条内容最多引 1–2 本」约束），它的作用是逼你把边界想出来。
找不到时不许跳过：写一句「暂未找到能限定它的理论」，并按 `feedback_rules P2` 走**收窄**。

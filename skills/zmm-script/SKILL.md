## 说给谁听

**单人自采自编的知识型创作者。** 三条硬约束（与商业集同源）：

1. **不假设他有团队。** 拍摄、剪辑、发布都是他一个人，方案要能一个人执行完
2. **不用向上汇报。** 他自己拍板，直接给判断和动作，不写「供参考」
3. **零术语。** 理论照用，名词不出现——不说「信息缺口」，说「让他先觉得自己不知道」

## 信条（非谈判项）

1. **从单元装配，不凭空写**：骨架 = QST 问题 → CON 概念 → OPI 观点 → CAS 案例（自做优先）→ SOL 方案（`口播生成标准.md` 第一条）。凭空写出来的「案例」就是编的，违反卖真红线。
2. **具象 > 抽象**：一个词要是还得先解释一遍，它就不该出现在口播里；❌「我努力创业成为富豪」✅「花 2 万在重庆开 20 平面馆，一个月赚 20 万」。抽象变具象两招：类比/比喻、借共识。
3. **给画面不给概念，小孩听得懂才算**：一句话要能让人看见东西，不是理解一个概念；多用量词、动词、名词，少用形容词。
4. **可照做标准**：每个点都要给一个观众今天就能原样执行的动作，不准玄学。判据是「他不用再问一句『具体怎么做』」（❌「要有活人感」✅「录之前把手机架在窗边，人离镜头一臂远」）。
5. **信息密度决定流量，短是密度的短**；观众愿意听下去的理由只有一个：这句够稀缺、够陌生、别处没听过。
6. **干货核心是收获感，不是真有用** + 低行动成本 + 确定性（「躺着刷手机都能瘦」式承诺结构，但守卖真红线）。
7. **AI 是让人思考更深的工具**：你负责结构、密度、装配；真实的体验、情绪、细节必须来自 用户——挖不到就问他要，不要替他编。

## 工作流程

**Phase 0：接题 + 判断这次要做多少。**

先看 用户拿来的是什么，**主动问清他要的是整稿还是一个零件**——很多时候他只想要开头或标题，硬拉他走完整流程是浪费：

> 这次是要**写整稿**，还是只要其中一块？
> 1. 整稿（选题 → 分镜稿）
> 2. 只要开头（已有稿或已有题，想换几个钩子）
> 3. 只要标题 / 封面大字
> 4. 只要公众号图文版

- 选 **1** → 走下面完整流程。
- 选 **2** → **直接进本技能的〈开头模式〉**（Phase 3 单独跑，出 3 个候选）。他要更多候选或要门禁诊断（怀疑是内容没货不是开头问题）→ 接力 `/zmm-hook`。
- 选 **3** → 接力 `/zmm-title`（他只要标题，那是换工作模式 = 接力；**写整稿时要标题则是调用**，见家族公约·八）。
- 选 **4** → 接力 `/zmm-post`。
- **上下文已经说清楚要哪个就不问**（比如他直接贴了一段稿说「开头再来几个」= 选 2）。

输入是选题（最好来自 `/zmm-topic`，在 `06-选题装配/选题管道.md` 有记录）。没有选题且他要整稿 → 回 `/zmm-topic`。有整稿要改 → `/zmm-review` 先诊断。

**Phase 1：定型（一次确认）。** **默认形态 = 知识付费口播（干货型/解答型）**——用户 2026-07-07 定（`08-技能记忆/_通用/20260707-默认形态是知识付费口播.md`）。除非他明确要别的、或素材明显更适合其他形态，否则按默认走，只确认干货七形式里取哪个 + 时长。完整菜单备查：

| 类型 | 结构 | 时长依据 |
|---|---|---|
| 干货型（七形式：避坑/省钱/谈资/追求更好/内幕揭秘/行业黑话/解决问题） | 钩子 → 3–5 个可照做点 → 获得感落点 | **避开 30–60s 和 300s+，其余按内容定**（N1，实证规律库：全量池 n=541 无「1–2 分钟甜点区」） |
| 解答型（干货子型） | 四拍：日常难题 → 制造危机 → 低行动成本 → 解决方法（`04-模板/解答型口播稿模板.md`） | 1–2 分钟 |
| 情绪/观点型（三触发：热点/共情/吐槽） | 总分总：争议话题+圈定人群+立看法 → 强制 3 论点 → 总结 | 1–3 分钟 |
| 个人故事型 | 五段：开场钩子 → 磨难 → 转机 → 磨难 → 转机 → 感悟 | 3–8 分钟 |
| 记录/挑战型 | 真人实拍纪实（爆点前置 2–4 场景快切、固定自我介绍、话术只定框架现场发挥、分段录制，见 `逆向-脚本形态库.md` 附B） | 5–8 分钟（对标账号卧底面试 463s） |

**增量形态菜单**：`00-规则与索引/逆向-脚本形态库.md` 另有 8 张形态卡（快问快答、快判断、情景OS教学、情景对立避坑、黑幕揭秘、案例故事递进、人生浓缩、见证我翻盘），每张带难度和填充物要求——**素材有什么选什么形态，不硬凑**（案例递进 4.5 级没真实案例就降级用快问快答）。

情绪型两个顺手的写法：替一群人把他们一直想干却没干成的事找到能对外讲的原因；或者替他们把其实不想干的事找到拒绝的底气。

**Phase 2：拉弹药（动手，报清单）。**
1. `surface_candidates.py --kw` 拉本人素材 + 相关内容单元（`02-内容单元库/`，用主题地图定位）。
2. 涉及 AI 事实 → `知识库/AI参考/` 核对，标注出处。
3. 涉及个人经历 → 只用 `我的素材/` canonical 版本（负债故事只用公域版）；**素材是空的就停下来问用户要真事**。故事型用「曲折事件五问」挖（`逆向-脚本形态库.md` 附A：后来做了什么项目→为什么看好→哪一步出问题→最直接损失→以为结束了还有更糟的一下），每问追到时间、地点、数字、当时的一句话——挖到能看见画面的细节才算挖到。
4. 把装配表（段 → 单元 ID → 要点）给用户 过目再动笔。

**Phase 3：开头（3 个候选，停）。** 按三种起手各出一个：①先让情绪失衡 ②先点名是谁 ③先反着说。每个都守开头公式（话题+Hook+可信度）、陈述句不自问自答、大白话。用户挑或改。要更多候选/深度诊断 → 转 `/zmm-hook`。

**Phase 4：主体逐段共创。** 一次写一段（一个点），写完停：这段的具象细节对不对？密度够不够？用户确认再写下一段。每段自检：有没有需要解释的词、有没有可照做动作、专业名词出现没有（名词一出来，观众就开始掉）。

**Phase 5：收尾。** 获得感落点（一句「看完带走什么」）+ 「我有什么」当事实带过（把产品或服务当叙述里的一件事提一句，证明你真做过；**不写任何行动指令** —— 「关注我」「私信我」「扣 1」一句都不要，转化靠频率 × 质量 × 判断方式被认同）。双编码自检：老板听到什么 / 小白听到什么。

**Phase 6：落盘与回写。** 成稿存 `_草稿/NN_口播_{标题}.md`（frontmatter 按 `04-模板/口播稿.md`）；新沉淀的观点/案例回写 `02-内容单元库/`；报路径。推荐下一步 `/zmm-review`。

## 故事型口径：推理叙事，不是苦情叙事

**个人故事型稿子最容易滑向苦情。** 硬口径：

| | 苦情叙事（不要） | **推理叙事（走这条）** |
|---|---|---|
| 讲什么 | 我多不容易 | **我当时是怎么判断的，错在哪** |
| 观众得到 | 同情 / 敬佩 | **一次可复用的推理** |
| 结果 | 崇拜——脆弱，一次翻车就崩 | 同类——稳固，本来就没说自己不会错 |

**判据**：讲完之后观众能不能带走一次判断，而不只是一个情绪。
带不走 = 还是苦情，回去改。

> 例：负债类故事不讲成惨，讲成一次判断失误的复盘——
> 「分清消费、负债、资产，我为这一课交了四百多万学费」。
> 磨难-转机的结构不变，但**每一段磨难都要落在「当时我是怎么想的、哪里想错了」上**。

⚠️ 这条与「不塑造不会错的形象」配套：**错了要讲出来，那是燃料，不是丑闻。**
→ 依据见 `zmm/references/认知框架.md` 定位后果一节

## 🔴 先判断：这条是论证型还是概念型（2026-08-24 加）

**默认会滑向论证型，而论证型没有获得感。** 动笔前先答一句：

> **这条稿要交给观众的那个概念，他能不能拿去解释一件我没提过的事？**

- 能 → 走概念型七拍（`references/概念型口播.md`），**第二个场景必须跨出本行业**
- 不能 → 你手上还是一个观点，不是一个概念。**回 `/zmm-topic` 用常识缺口法重新找**，
  或者接受它就是一条观点型稿子并说清楚（观点型不是不能做，是不能假装有知识感）

⚠️ **概念型与下面的亮路径三幕不冲突**：三幕管「我怎么得到这个概念」（路径，差异化），
概念型七拍管「我怎么把它交给你」（结构，获得感）。**④「我是怎么推理的」照样是差异化的全部来源。**

## 亮路径三幕（默认骨架）

观众记住一个人，不是因为他给的结论有用（有用的结论满街都是），是因为看见了他**怎么走到那个结论的**。所以稿子的骨架不是「结论 + 证据 + 好评」，是一条路：

```
第一幕 · 撞上
  ① 我碰到了什么事
  ② 哪里不对劲（和我以为的不一样）
  ③ 老办法为什么在这儿失灵
第二幕 · 想通            ← 全稿只有这一幕别人抄不走，也最容易被作者跳过
  ④ 我是怎么一步步想的
  ⑤ 想到最后定了什么
第三幕 · 做完
  ⑥ 照着做了什么
  ⑦ 结果是什么
  ⑧ 回头看学到什么
  ⑨ 换成你，明天能改什么
```

> **两个人可以得出同一个结论，但不会走同一条路。** 结论会重合，路径不会。第二幕写不出来，整条稿就退回「展示专业」——那种人人都在做、观众早已免疫的形状。

### ★ 但差异化有两层，别把它们混成一件事（2026-08-24 补）

```
路径层 = 你怎么走到结论的     ← 已经在你身上了，不需要试，需要的是讲出来
讲法层 = 你用什么样子讲     ← 这个你没有现成的，只能一版一版试，试中了放大，试不中换
```

🔴 **两句流行说法各说了一半，合起来才对：**
「与众不同的是你走到结论的路」讲的是路径层；
「与众不同是试出来的，不是想出来的」讲的是讲法层。
**拿后一句去否定前一句，会让人以为路径也要靠试——路径不用试，它已经在那儿了。**

**有路径没讲法** = 东西是对的，但没人看到。
**有讲法没路径** = 壳好看，里面是空的，而且壳谁都能照着做（讲法摆在明面上，路径不在）。

⚠️ **讲法能试的范围被账号定位框住。** 第一人称换第二人称、从别的场景切进来、换一种证据
（数据 / 原典 / 亲历）、换节奏 —— 这些都可以试。
但账号立的是「真实、不表演」的话，**演角色、套梗、拟人设定这些壳就是在往外掉分**，
试出效果也不能放大。**先看 `config.paths.voice`，再决定试哪些。**

不必九拍全占，但 **第二幕必须有**。只有结论没有推理过程 = 又变回展示专业。

→ 判断层依据见 `zmm/references/认知框架.md`

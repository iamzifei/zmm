# 规则卡

> 本技能内置的判据。每张卡：判据 / 为什么 / 怎么查 / 例子 / 强度（硬 = 不可商量；实测 = 有数据，数值是本系统实测，换账号要重测；经验 = 用过有效，未量化）。
> 作者环境里 `{vault}` 有对应的规则文件时，**以 vault 为准，本文件为底**；两处不一致先按 vault 做，再回来修这里。
> 卡片之间互相引用用卡名。

## 审核与红线 · 流程与协作

### 验证前置：先把每个循环的验货关卡写死，再放大生成端；没有关卡的循环不上线
- 判据：任何自动化循环上线前先定义「什么算通过」，关卡没写清楚不许放量。
- 为什么：先放大生成端会把废稿放大。
- 怎么查：循环定义里「验证关卡」栏为空 → 不上线。
- 例子：（用占位）
- 强度：经验

### 循环不越权：只产草稿和候选，公域发布永远过人
- 判据：自动循环的产物只能是候选和草稿；发布是人的动作，不可自动化。
- 为什么：这是自动化的边界，作者本人是最后一道。
- 怎么查：任何自动流程的最后一步不能是「发布」。
- 例子：（用占位）
- 强度：硬

### 循环指令引用规则文件，不把规则抄进提示词
- 判据：循环的指令里写「按某文件扫」，不把词表或判据复制进提示词。
- 为什么：规则更新时循环自动跟上；抄进去就会漂移。
- 怎么查：提示词里出现判据正文 → 改成引用。
- 例子：（用占位）
- 强度：经验

### 每轮留痕：每跑一轮记录到状态文件，可追溯可回滚
- 判据：循环每轮的输入、产出、判定写入对应的日志或候选清单。
- 为什么：不留痕就无法知道哪一轮出的问题。
- 怎么查：日志文件行数随轮次增长。
- 例子：（用占位）
- 强度：经验

### 先半自动跑三轮，关卡稳了再挂定时
- 判据：新循环先由人手动触发跑三轮，验证关卡表现稳定后再挂定时任务。
- 为什么：直接挂定时的循环出错时没人在看。
- 怎么查：定时任务配置前有三轮手动记录。
- 例子：（用占位）
- 强度：经验

### 自动改写最多三轮，三轮仍不过标「待人工」停下
- 判据：验证不通过自动改写重扫，上限三轮；三轮仍不过不再循环，标记待人工。
- 为什么：防止改写循环空转。
- 怎么查：改写记录里轮次不超过三。
- 例子：（用占位）
- 强度：经验

### 人的位置只有两个：勾选题、终审放行；其余时间留给拍摄和真实业务
- 判据：循环化之后人只做两件事：从候选里勾 1–3 个题（唯一必做的人工输入）、终审放行（唯一发布闸门），加每周读一次复盘并改一次规则。
- 为什么：循环替代的是打字，不是活人；真实战绩才是素材之源。
- 怎么查：一天里人的动作超过这两件 → 某个环节没循环化。
- 例子：（用占位）
- 强度：经验

### 转述外部数据带限定语，回查来源文件
- 判据：稿里引用的数字、引述回查来源文件；转述访谈或二手数据时带「据某某整理」类限定，不写成事实。
- 为什么：二手数字写成事实，错了就是你的错。
- 怎么查：事实核对清单每条带来源。
- 例子：（用占位）
- 强度：经验

# 锁四样：写整稿之前必须先钉死的四句话

> **这是 `zmm-concept` 唯一自带操作内容的文件。** 其余判据全部指回既有文件 —— **复制就会漂**。
> **实测代价**：N22 v1–v6 六版返工，逐版对因见 `SKILL.md`。

## 输出形态：一页纸，四行

**不是提纲，不是骨架，是四句话。** 交给他的时候长这样：

```
① 具体问题   为什么定价越低，卖得越不好？
② 本体定义   定价不是一个数字，它本身就属于产品的一部分
③ 理论/靶子  李普曼《公众舆论》1922「先定义，然后才看见」
             + 商学院三分法：成本导向 / 竞争导向 / 价值导向
④ 通俗类比   超市打折的水果 · 连真皮都不是的奢侈品包
```

**四行确认了，整稿基本一次成。**

## ① 具体问题

**要的是一个问题，不是一个词条。**

```
❌ 「什么是定价」              —— 词条。观众没有理由点进来
✅ 「为什么定价越低，卖得越不好」 —— 问题，概念藏在答案里
```

📄 依据 `作者方法论 §5.32`（詹明明 2026-08-14 原话）：「**一条内容应该针对一个具体的问题或者一个具体的解决方案来做**，而这个具体的问题应该是具有普适性或者具有吸引力的。」

### 🔴 两条判据，逐条答

| # | 问 | 答不对 = |
|---|---|---|
| **a** | 这个问题，**他上个月真的碰到过**吗？还是我为了引出这个概念设计出来的？ | 设计出来的 = 换。<br>补充检查：场景里有没有一个「**刚好**」？有「刚好」就是构造的 |
| **b** | 这个问题**解困**还是**增益**？ | 增益型 = 换（`常识缺口法 ⓪-2`，实测代价一整版稿）<br>✅「我降了价人没多来」　❌「涨价没那么可怕」 |

⚠️ **AI 提 3 个候选就够，让他挑或改。不要一个人定。**

## ② 🔴 本体定义 / 反常识那一句 —— **只能他给**

**这是四样里唯一 AI 给不出来的，也是六版返工的根。**

### 分辨：功能描述 vs 本体定义

| | 例 | |
|---|---|---|
| **功能描述**（AI 写得出来） | 「定价同时在回答三个问题」 | 说的是**它干什么** |
| ★ **本体定义**（只有他给得出） | **「定价不是一个数字，它本身就属于产品的一部分」** | 说的是**它是什么** |

🔑 **有了本体定义，后面的框架才有地基。** N22 v6 只有功能描述，所以三个问题是悬着的；
v7 他一开口给出本体定义，下一句就自动长出了反常识结论 ——
**「你抄了对手的产品，但价格跟他不一样，你和你的竞品就已经不是同一个产品了」。**

### 🔴 拿不到就停，不许用别的顶

**三种最常见的顶替，全部是返工信号：**

| 顶替物 | N22 实测 |
|---|---|
| 用**他的经历**顶 | v1 · v2 · v4 —— 「我竞品卖 40 我定 45」占了 31% 篇幅，仍然不是骨架 |
| 用**理论**顶 | v3 —— 韦伯定律很漂亮，但它解释的是另一个命题 |
| 用**框架**顶 | v6 —— 「三个问题」是功能描述，不是本体定义 |

**怎么问他**（一次问完，不要来回）：

> 「这个概念，如果用一句话说清它**到底是什么**（不是它干什么），你会怎么说？」

⚠️ **他给出来的那句话，一个字都不要改**（`作者方法论 §5.0` 维护②）。

### ★ 拿到本体定义之后，再试一步：把它写成**分类刀**

**同一个纠偏，有两种刀。默认会写成能力刀，而分类刀更强。**

| | 说的是 | N23 实例 |
|---|---|---|
| ❌ **能力刀** | **你做不到那件事** | 「不投流的时候，你没有『瞄准』这个动作可以做」 |
| ★ **分类刀** | **你做的那件事不叫 X，它叫 Y** | **「你可以有精准营销，但不应该有精准流量」** |

🔑 **分类刀为什么更强**：
① **零防御** —— 观众不用承认自己错了，只要接受一个更清楚的分法
② **自带迁移** —— 分法拿到手，他能去分你没提过的事（这正是准入闸门②「尺子判据」）
③ **可证伪** —— 两个类别的边界说得出来；「你做不到」说不出来

> ## 🔴 判据：我能不能把这句「你做不到 X」，改写成「你做的那件事不叫 X，它叫 Y」？
> 能改 = 改。⚠️ **Y 必须是观众本来就懂的词**，否则挂靠点就没了（N23 的 Y 是「精准营销」，人人懂）。

⚠️ **N23 实测**：AI 稿从头到尾都是能力刀，**直到他开口才变成分类刀**。
⇒ **这一步在锁四样阶段就试，不要等复述。**

### 3b · 学科通识靶子（给专业感）

🟢 **詹明明 原话（2026-08-28）**：「商学院里面是不是有关于定价的一个理论？我觉得把那个理论当做一个通识先介绍一下，**这样可以显示出我的视角的不同。不然人家专业点的会觉得我是野路子。**」

**通识不走引用纪律**：

> **判据：这个说法在任何一本同类教材里都能找到吗？**
> 能 = 通识，**直接讲，不必点名作者书名**
> 只在某一本里 = 引用，走 `E1–E5` + `§1.65` 全套

⚠️ **报通识不点名最稳**：说「商学院里叫成本导向」零风险；说「某某在某书第几页说」就得能 grep。

🔥 **通识的真正用法是当靶子**：把教科书那套摆出来，**然后指出它漏了哪一层** ——
那一层就是你的视角。N22：教科书把「定价方法」和「市场细分」分成两章，他把它们连成一件事。

## ④ 2–3 个通俗类比

### 硬判据：**观众站在买家位置，还是卖家位置？**

| | 例 | 判 |
|---|---|---|
| ❌ | 用奢侈品证明「**高价有效，你也该这么定**」 | 观众是**卖家**，他的产品不是劳力士，挂不上 |
| ✅ | 用奢侈品证明「**价格是产品的一部分**」 | 观众是**买家**，人人见过，是共有体验 |

🟢 **N22 实测的四个好类比**，都在买家位置：
**超市打折的水果**（翻过来看日期）· **连真皮都不是的奢侈品包** · **满两百减一百 vs 直接改成一百** · **应聘时把期待薪资报低**

### 另外三条

| # | 规则 | 一句话 |
|---|---|---|
| **a** | **选观众站着的那一层** | 同一个现象能在品牌战略层 / 产品层 / **消费者心理层**解释。**高一层观众够不着，低一层观众不关心** |
| **b** | **优先用中国观众共有的典故** | 有典故就**用它并删掉你的解释**。N22 实测：AI 写 40 字翻译，他一句「就是苏东坡跟佛印那个故事」14 字解决 |
| **c** | `概念型口播 ⑥` **必须跨行业** | 「不要用同行业的第二个例子，那不叫第二个场景，那叫补充论据，观众感觉不到尺子」 |
| ★ **d** | **动作方向要对齐**（N23 加） | 好懂 ≠ 对。**这个类比里的人在做什么动作，和我主张的是同一个吗？**<br>❌ AI 稿用「姜太公钓鱼」—— 动作是**等**<br>🟢 他换成「**广撒网，上来了再挑要的鱼**」—— 动作是**捞了再挑**<br>🔴 他的主张就是「泛流量做大再层层筛」= 捞了再挑。**姜太公方向是反的。**<br>姜太公好懂、是典故、买家位置 —— **三条判据全过，动作方向错，所以它是错的类比。** |

### ★ 类比之外还有一手更省的：**归谬翻译**

**同一个位置，三种做法，一次比一次省：**

| 做法 | 长度 | 例 |
|---|---|---|
| 排除法 | 3 行 | 它不是 A，也不是 B，更不是 C |
| 本体定义 | 1 行 | 「一个正常的商业漏斗无非就是流量，然后转化」 |
| ★ **归谬** | **半行** | **「流量还有泛的吗？就是我想做一个内容，我不希望它被大多数人看见。」** |

🔑 **机制**：前两种是**你在给定义**；归谬是**你照着对方的词念一遍**，荒谬感由观众自己产生。
⇒ 同时兑现「误区的判断必须由观众自己生成」和「零说教」—— **你一句评价都没给。**

> 🔴 **判据：把这个词的字面意思当成一个真实动作念出来，听着荒不荒谬？**
> 荒谬 = 用归谬，一句顶三句　　不荒谬 = 退回本体定义，再退回排除法

⚠️ **限制**：只对**由对立面定义的词**有效（泛/精准 · 快/慢 · 轻/重）。
单极词（转化、留存）没有反面可念，用不了。

⚠️ **类比不得编数字**。用人人可自查的日常处境，数据留给本行业那个场景用。

## 锁完之后：一句话确认

交给他之前，自己先答一遍：

- [ ] ① 这个问题他上个月真碰到过，而且是解困型
- [ ] ② 本体定义是**他给的原话**，不是我写的功能描述
- [ ] ③ 理论五维 ≥7 且机制匹配 ≥3；通识靶子指出了教科书漏掉的那一层
- [ ] ④ 每个类比里，观众都站在**买家**位置；至少一个跨出他的行业；**每个类比的动作方向和主张一致**
- [ ] ★ **落点试过分类刀了吗**——「你做不到 X」能不能改成「那件事不叫 X，它叫 Y」
- [ ] ★ **这个词是由对立面定义的吗**（泛/精准、快/慢）——是的话，试一次归谬，它比类比更省

> ## 🔴 前四个都打勾，才动手写整稿。

> 后两个是**增强项**，锁不到不挡路 —— 但 **N23 实测这两样都是他自己开口才有的**，

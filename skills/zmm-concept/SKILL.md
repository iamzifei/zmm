先读 `zmm/references/家族公约.md`（读不到 → 明说「公约读不到，红线无法保证」并停下，**不凭记忆代替公约**），

## 🔴 它在最短路径上的位置：**代替 `/zmm-script`，不是加在它旁边**

```
选题 → 【重讲概念型走这儿】→ 红线审核 → 发
```

⚠️ **`zmm` 路由记着一条实测**：本系统曾经有 7 道发布前闸门，结果 13 条成稿、0 条发布。
**闸门数量本身就是不发布的成因。**
🔴 **本技能不新增任何闸门。** 它只做一件事：**把已经会发生的返工，提前到一页纸上发生。**

## 这个技能为什么存在（实测代价，别删）

**N22《定价越低，卖得越不好》走了 12 版。** 12 版里真正起作用的只有两次：
① 詹明明 说「**我的经历不能当主体，抖音大众够不着**」 ② **他自己开口了**。

**其余九版是在猜他要什么，而每次猜错的原因是同一个：先写了整稿，才发现命题层不对。**

| 版本 | 死在哪 |
|---|---|
| v1 · v2 · v4 | **本体定义没锁**，用「他的经历」顶上去 |
| v3 | **理论没锁**（韦伯解释的是「降了没感觉」，不是「降了没人买」） |
| v5 · v6 | **命题没锁**（从「讲一个点」变成「讲整件事」） |

> ## ⇒ 六版返工，全部死在同样四样东西上。而那四样，每样只要一句话。

### 🟢 N23《没有精准流量》验证了它有效 —— 但把问题推到了下游（2026-08-29）

**N23 复述 v1 就基本可用，只迭代到 v4，没有一次是命题层返工。锁四样成立。**

🔴 **但这一条丢掉的东西，全部丢在 Phase 3–5：**

| 丢了什么 | 死在哪一步 | 代价 |
|---|---|---|
| **嘴替句**（`V3` 转发驱动的唯一来源） | **Phase 4** —— 我写进了「建议加回」，他批准了，**我只落了另一处，这句从没进过正文** | 成片里没有。该条的转发判据**读不出来** |
| **落点换了没被当成换稿** | **Phase 3 后** —— 能力刀 → 分类刀，而落点句是「稿子的身份证」 | frontmatter / 标题 / 文件名一度还挂着旧落点 |
| **按错的语速参数否掉了对的开场** | **Phase 2** —— 用 ÷5.1 点值算前 5 秒预算，判「和高客单」装不下 | 他成片里加回去了，**装得下。实测 6.88，参数错 35%** |

🔴 **横切层永远在**：`CLAUDE.md` 地板第 7 条 —— **每写完一段，用「我」重读一遍，写出他此刻那句内心话。写不出来＝这段还没写完。通篇不许有指责和说教的味道。**

## 流程

```
Phase 0  接题 + 两道准入闸门
Phase 1  🔴 锁四样（一页纸，不写整稿）   ← 本技能的全部价值
Phase 2  写整稿（一次写完，不逐段确认）
Phase 3  🔴 交给他口述（D1）
Phase 4  只剪不扩 + 红线全表 + 差异表 + 规则入库
Phase 5  /zmm-title 归口 + 封面 + 落盘 + 建取数日历
```

### Phase 0 · 接题 + 准入（不问废话）

题从 `{config.paths.topic_pipeline}` 所在目录的选题池取，或用户新给。

**两道闸门，缺一不做**（判据在池子 §2.3，去读，不要凭记忆）：

| # | 闸门 | 一句话 |
|---|---|---|
| ① | **`V7` 挂靠点** | 他听到你的新说法之前，**有没有一个他本来就熟的词被你先拆开**？ |
| ② | **尺子判据** | 你交出去的东西，**他能不能拿去量一件你没提过的事**？量不了 = 那还是个定义 |

**顺手过一次去重闸门**（`总入口` §2 第 1 层）：核心结论 × 主类比比对 + **写出姊妹条是哪条**。

### Phase 1 · 🔴 锁四样（本技能的核心，见 `references/锁四样.md`）

**一次问完，一页纸，不写整稿。**

| # | 锁什么 | 谁给 |
|---|---|---|
| 1 | **具体问题** | AI 提候选，**他定** |
| 2 | 🔴 **本体定义 / 反常识那一句** | **只能他给** |
| 3 | **经典理论 + 学科通识靶子** | AI 找并五维评分，**他确认** |
| 4 | **2–3 个通俗类比** | AI 提，**他换** |

> ## 🔴 四样没锁齐，不许写整稿。

⚠️ **第 2 样最容易被跳过，而它正是六版返工的根**。
AI 写不出「定价本身就属于产品的一部分」这种句子 —— 它只能写出功能描述（「定价在回答三个问题」）。
**拿不到第 2 样，就停在这儿等，不要用理论或经历去顶。**

### Phase 2 · 写整稿（一次写完）

按 `{vault}/04-模板/概念纠偏型口播稿模板.md` 六段。
**⑤ 段内部按 `zmm-script/references/概念型口播.md` 七拍** —— 🔴 **必须打开读，两拍最容易漏**：
**② 替观众说出他的答案**（「最容易漏的一拍，决定成败」）· **⑥ 跨行业第二场景**（「获得感全部来自这一拍」）。

出稿即报三件：**时长区间** · **缺口分布表**（算秒数）· **红线全表扫描结果**。

🔴 **时长只给区间，不给点值**（2026-08-29 `总入口 §3 #2` 重裁）：

```
原速区间 = 稿面汉字 ÷ 6.9   ~   ÷ 5.1
```

🔴🔴 **2026-08-31 更正（`F13`）：上面这段的依据曾经是错的，别照旧版执行。**
**实测确认成片用了 1.2× 倍速** ⇒ **6.88 是成片速，不是口播速**。
**原速 = 1583 ÷ (230×1.2) = 5.74 字/秒。**

⇒ 08-29 推翻旧裁定时写的理由是「N19 5.1 vs N23 6.88，**离散 35%**」——
**除掉倍速后是 5.1 vs 5.74，离散 12.5%。那个理由不成立了。**
🔴 **三条概念型的原速语速反而相当集中**：N19 **5.1** · N20 **5.32** · N23 **5.74**。
⛔ **但不擅自恢复旧裁定** —— 缺一个数：**N16 的 6.4 是否也是加速后的数，未核实。**
⇒ `总入口 §3 裁定 #2` 已标「依据失效，待重核」，判完回写。

🔴 **出稿动作（frontmatter 四个字段一起写，缺一不算回填）**：
`稿面字数` / `成片秒数` / **`倍速系数`** / `原速语速 = 字数 ÷ (成片秒数 × 倍速)`
⚠️ **两个速率不要互换**：算稿子长度用**原速**；算前 2/3/5 秒装得下多少字用**成片速**
（抖音的 `2s 跳出 / 5s 完播 / 观看趋势` 全都在成片时间轴上）。

🔴🔴 **用时长去否一个句子之前，先问一句：35% 的误差会不会翻转这个结论？**
**N23 实测代价**：我按 ÷5.1 算前 5 秒只装得下 21 字，据此否掉了他想加的「和高客单」。
**他成片里加回去了，而且装得下。** —— **参数不确定的时候，不要拿它当否决权。**

🔴 **交出去的时候必须明说：这一版是给你口述用的底稿，不是成稿。**

### Phase 3 · 🔴 交给他口述（`D1`）

**没复述不许拍。** 口述回来 → **原样留档** → 再处理。

#### 🔴 口述回来的第一件事：核落点变没变（N23 加）

**不是核措辞，是核落点。** `口播稿输出格式`：**落点句是这条稿子的身份证 —— 换了落点句就是换了稿，不是改稿。**

> ## 问一句：他说的那个落点，和你锁的那个，**是同一句话吗？**

**N23 实测：不是，而且他的更好。**

| | AI 稿 | 他复述 |
|---|---|---|
| 落点 | 不投流时你没有「瞄准」这个动作 | **你可以有精准营销，但不应该有精准流量** |
| 是什么刀 | **能力刀**（你做不到） | ★ **分类刀**（那件事叫别的名字） |

⇒ **落点变了 = 当场改四样东西**：frontmatter 落点句 · 作品标题 · 封面大字 · **文件名**。
🔴 **不要拖到发布前** —— N23 一度还挂着旧落点。

⚠️ **落点变了通常是变好了**（他在推理，AI 在描述）。**这一步是去捕捉它，不是去纠正他。**

### Phase 4 · 只剪不扩

`D2`：**优化只能从复述稿剪，不能从任何 AI 稿往上扩。**

**四件必做**：
1. **红线全表**（`违禁词避雷表` 10 类 + 绝对化 + 符号级）—— 🔴 **不是 grep 四个词**
2. **人称统一**（`A11`：讲机制用泛指词全篇统一；只有讲具体行业场景才切换，且只切那一段）
3. **内部一致性**（`发布前审核流程` 第 10 关：全文数字/时间/事实前后对不对得上）
4. **差异表 + 规则入库**（`总入口` §5 四步：原话入档 → 判归属层 → 写成可执行判据 → 附实测代价）

#### 🔴🔴 第五件（N23 加，因为我漏了它）：**批准加回的东西，必须当场落正文并 grep 验证**

`D2` 说「不能从 AI 稿往上扩」，所以差异表里「他删掉的」那些**只能列出来问**，不许自己加回。
**但他批准之后呢？** —— 原来的流程到这儿就断了。

**N23 实测代价**：嘴替句（`V3` 转发驱动的**唯一**来源）他 08-29 就批准加回，
**我只落了另一处，这句从没进过正文** ⇒ 成片里没有 ⇒ 那条判据这一次读不出来。

🔴 **三步，缺一不可**：

```
① 他批准        →  ② 当场落进正文（不是写进"建议"栏）  →  ③ grep 原句验证在不在
```

⚠️ **`F6` 已经教过一次同样的事**：📣 清单引原句不引行号，因为**行号会静默指向别的句子**。
**本条是它的同类**：写在建议栏里的句子**会静默地不存在**。
**判据：改完之后，grep 那句原文。grep 不到 = 它就是不在。**

### Phase 5 · 标题封面 + 画面 + 落盘

标题封面**走 `/zmm-title` 归口**（要标结构编号 S1–S12，且要回答「按这个标题正文开头要不要改」）。
成稿落 `{vault}/_草稿/NN_认知_{标题}.md`，格式按 `00-规则与索引/口播稿输出格式.md`。
**文件名与稿子的落点必须一致** —— 落点变了就改名，别拖到发布前。

#### 🔴 封面素材在哪（N23 加：我找错过一次目录）

```
docs/brand/design-system.md          ← 视觉系统（暖白纸底 · 档案绿 · 宋体黑 · 刻度线母题）

docs/brand/douyin/cover-00X.*         ← 已发的封面，看它们对齐风格
```

⚠️ **不在 `_装修/`。** N23 我只搜了 `_装修` 和 `_已发布`，**没搜 `docs/`**，
结果做了一版白底黑字纯文字封面，脱离整套视觉系统，作废重做。

**模板的两条硬规则**（写在模板注释里，去读）：
- **封面大字每行 ≤6 字，最多两行**（`口播稿输出格式` 2026-08-29 订正措辞：原写「≤6 字」漏了「每行」）

#### 🔴🔴 取封面帧的坑：字幕是烧进画面的

**模板的标题区正好压在字幕带上。** N23 实测：字幕带在 y1400–1520（画面 75% 处）。

> **不要随手截一帧。** 按 1.5 秒采样全片 → 程序化筛字幕带干净的 → 再按头部区对比度排序。
> **N23 实测：143 帧里只有 4 帧没字幕。**

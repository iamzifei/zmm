# 三筛判据（/zmm-benchmark 专用）

> 判「这个人值不值得学」。三个筛子按顺序过，**任何一个不通过就换下一个候选**，不要凑合。

---

## 这套判据从哪来，改了什么

底子是一套流传很广的「五重过滤法」，那套是找**生意**对标用的。本技能找的是**内容**对标，故意改了三处。
**下面每一处分歧都是设计取舍，不是实测结论 —— 如实标注，不许说成「数据表明」。**

| # | 原版 | 本技能 | 为什么改 |
|---|---|---|---|
| 1 | 筛子「排除自我」：不讨论个人经历、资源、优劣势 | **保留能力匹配，作为筛子 3** | 内容的可复制性高度依赖一手素材、经历、人设信任。抄一个你讲不了的题，抄不动；抄不动之后人会把它归因成「我不适合做内容」，代价远大于多问一句 |
| 2 | 筛子「不讨论业务本质」 | **删掉**（内容对标里没有对应物） | —— |
| 3 | 没有分母要求 | **爆款批必须配全量分母** | 本系统赔过一次：从某对标 TOP100 归纳出「1–2 分钟甜点区」，回全量池 n=541 效应消失（`zmm/references/实证规律库.md` N1） |

保留不动的：**收入门槛 ≥ 当前收入 × 10**（2026-09-03 用户当场确认照原版，不设上限）。

## 筛子 1 · 他赚钱吗

**门槛：估算利润 ≥ 用户当前收入 × 10。**

### 怎么估（按可信度从高到低）

1. **他自己在卖什么**——课程页、社群、私域引流话术、小黄车、直播间挂的链接。有明码标价的最好估：`价格 × 估算成交量`
2. **他敢花多少钱**——投流痕迹、团队规模、场地、设备。**敢花钱是赚钱最硬的旁证**，因为花钱是外部可见的，赚钱不是
3. **交付形态**——一对一咨询天花板低，标准化课程和社群才有量
4. 都看不到 → **写「看不出来」**，这就是筛子 1 不通过

### 三条不许犯的错

- 🔴 **粉丝多 ≠ 赚钱。** 百万粉的纯流量号可能一分钱不挣，两万粉的垂类号可能月入六位数。**只看粉丝数就判赚钱，是这个筛子最常见的失败**
- 🔴 **点赞多 ≠ 赚钱。** 同上
- 🔴 **收入几乎一定只能是「推断」级。** 外部看不到真实营收。写卡片时如实标注，并附一句「如果我错了，最可能错在哪」（例：如果他的课其实卖不动、只是页面挂着，我这个估算会高一个量级）

### 为什么门槛是 10 倍而不是 2 倍

学一个比你强一点的人，你学到的是**他的运气**；学一个比你强一个量级的人，你才被迫去看**结构差异**。
2 倍的差距用「他运气好」就能解释掉，10 倍解释不掉。

## 筛子 2 · 你看得懂吗

**门槛：获客 → 转化 → 交付 → 复购，四段都能用一句话说清。**

| 段 | 要能回答 |
|---|---|
| 获客 | 陌生人从哪看到他？（自然流 / 投流 / 蹭话题 / 矩阵号） |
| 转化 | 从「看到」到「付钱」中间隔着什么？（私域 / 直播 / 主页挂链 / 评论区引导） |
| 交付 | 他卖的东西怎么送到手上？（录播 / 直播课 / 社群 / 一对一 / 实物） |
| 复购 | 有没有第二次？还是一锤子买卖？ |

**四段里有一段说不清 → 筛子 2 不通过。**

这不是苛刻。看不懂的意思是：你抄了他的内容形态，但不知道那个形态是为哪一步服务的，
于是你会**抄掉一个正在做转化的动作，把它当成内容做**——做出来观感对了，但不通向任何收钱的地方。

> **允许的例外**：不需要懂全部细节，只需要懂主干。他的私域怎么运营的你不用知道，
> 但「他有私域、内容是往私域导的」这句你必须知道。

## 筛子 3 · 你仿得动吗（★ 本技能与原版分歧最大的一条）

**门槛：他这套内容依赖的能力、经历、素材，用户要么已经有，要么能在合理时间内长出来。**

### 逐条对，不要整体感觉

| 他依赖的 | 用户有吗 | 长得出来吗 |
|---|---|---|
| 某个行业身份 | | 换不了的身份 → 硬伤 |
| 一手战绩 / 真实数据 | | 要多久才能攒出来 |
| 某类一手素材（客户案例、后台截图、现场） | | 拿不到就抄不动 |
| 某种表达能力（把复杂讲成大白话、镜头感） | | 可练，但要标出练多久 |
| 制作能力（剪辑、拍摄、图文排版） | | 可外包 / 可降级 |

### 判定

- 硬伤（不可替换的身份或独家素材）**支撑着他的主要爆款** → **不通过**，换人
- 硬伤只支撑他的少数内容 → 通过，但在幕五的「不可迁移」栏里点名
- 全部可长出来 → 通过，并给出「要多久」

### 什么时候可以放宽

用户说「我就是想学他的表达方式，不想做他那个方向」——**这不是找对标，这是找风格参考**。
说清楚这个区别，然后按风格参考处理（只借表达，不借选题、不借商业模式），不要走完整的五幕。

---

## 方向匹配（不算筛子，是幕一的输入）

- **用户有想做的内容方向** → 对标方向要相似。差得太远的话，可迁移那一栏会空掉
- **用户没有方向** → **不要问他「你对什么感兴趣」**。兴趣问出来的方向撑不过第 20 条。
  问「你做过什么、别人常来问你什么」，从**能力和被需要的痕迹**反推方向，再拿这个方向去搜人

---

## 筛不出来怎么办

三个候选全挂 → **不要降低门槛凑一个出来**。回到幕一，换一句话说明白：

- 全挂在筛子 1 → 搜的关键词偏流量向了，换成带交易意图的词（「XX 怎么收费」「XX 接单」）
- 全挂在筛子 2 → 这个赛道的钱路对用户还是黑箱，**先做一轮行业理解，不是先做内容**
- 全挂在筛子 3 → 方向选错了，回到「你做过什么」重来一遍

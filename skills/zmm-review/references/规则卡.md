## 人群 · 口径 · 结构 · 忠实度 · 引用 · 判据 · 观众视角

### 命题过五问，逐条写判定
- 判据：绝对化（反例能不能轻易成立）· 因果跳跃（材料只展示了相关或感受却写成原因）· 定义偷换（核心词前后含义变了要明说）· 经验普遍化（单个案例扩成规律）· 反向推断（看到结果倒推唯一原因）。审完写判定：保留 / 收窄 / 重构 / 放弃，不许含糊。收窄不是认怂，范围收窄之后语气仍可说死。
- 强度：硬。

### 三档尺度管的是口播，不管画面
- 判据：这个数字是被念出来的，还是只被看到的？念出来 → 金额说量级、不出现「钱」字、收入不给币种；只被看到 → 不受限，数字和币种都可以出现。画面打码清单（必涂）：客户姓名、邮箱、公司名、产品名、账号名、浏览器地址栏；可以留：金额、币种、国别、日期。涂实心块，不用模糊或马赛克滤镜（低强度模糊可被还原）。
- 为什么：口播会进字幕、进语音识别、进平台文本审核；画面里的数字是像素，两条通道的审核路径不同。残余风险要写清：平台有图像识别，「收益后台截图」本身是一个视觉模式，本条降低风险但不消除。配套动作：画面给证据，口播一个数字都不念；若口播念了又影响合规，放弃念，不放弃画面。
- 强度：硬。

### 不点名：同行、地域群体、品牌（贬义语境）、公众人物
- 判据：成稿里不出现四类名字：同行和对标创作者；地域群体（「某地人都…」）；贬义语境下的品牌名；公众人物。对面要立成做法、惯例、处境，不立成人。
- 为什么：点名同行是免费送流量给别人；地域和公众人物是平台最先拦的两类；贬义语境下的品牌名有法律风险。
- 怎么查：红线扫描时把这四类连同 `config.redlines.no_naming` 一起扫；命中给不点名的改写（把人换成做法）。
- 例子：❌「某某老师那套方法早过时了」 ✅「那种先卖课再补内容的做法早过时了」
- 强度：硬。

### 「这样做其实也不是不行」句式必须换材料或删
- 判据：替灰色做法开脱的句式，命中即删或换材料。
- 例子：（用占位）
- 强度：硬。

### 法律与限流高压线：胎儿性别鉴定、性别对立话题、传授违规经营方法
- 判据：三类话题选题阶段就毙，不进写稿：涉及胎儿性别鉴定的任何内容；把两性对立当卖点的话题；教人怎么绕过规则经营（刷量、避税技巧、灰色获客）。
- 为什么：前两类是平台明文的限流和封禁项，第三类可能触及法律；这不是「改一改就能发」的红线，是「不该做」的题。
- 怎么查：选题过滤器和红线查各扫一遍；命中直接判「放弃」，不给改法。
- 例子：（用占位）
- 强度：硬。

### 不做转化动作，所有转化必须让观众觉得是他自发得到的结果
- 判据：出稿前答一句：这句话是在「展示我有什么」，还是在「让他去做什么」？后者 = 删。删：「想学的扣 1」「私信我拿模板」「有需要的可以找我」。留：把产品或服务当成叙述里的一个事实带过（「我那个订阅产品当时……」），它证明你真做过，不是在卖它。
- 为什么：转化靠的是频率 × 质量 × 认知展示，不是靠某一条里的那句话。刻意营销、推广、引导购买会破坏文案的整体性和专业性。
- 怎么查：审核里「凭什么是你」那一问原本要求「一个不过度强迫的行动指令」，行动指令这一半作废，只保留「我有什么 / 我能解决什么」，且必须长在内容里。
- 例子：（用占位）
- 强度：硬。

### 通篇不许有指责和说教的味道
- 判据：读完整条，有没有任何一处让他觉得「你在教我做事」？归因反转、指控第三方、第一句给有解、主语不是「你」四条管具体位置，这条是语气层的总闸。正面解法见「指令性开场紧跟收益」卡。
- 强度：硬。

### 判据是绝对观看时长不是完播率，对标读数只能当参照不能当目标
- 判据：5 分钟看 2 分钟胜过 1 分钟看 1 分钟；长是说清楚的结果不是目标。压时长之前先答一句：这一段删掉之后，那个东西还讲得清楚吗？讲不清楚 = 不删，超时也不删。对标读数里所有「他是多少」只能当参照：形式约束可以硬执行（封面字数），内容量不行。
- 为什么：数字一旦进了计划表就会被当成指标。
- 强度：硬。

### 字数不是判据，单位时间的有效信息才是
- 判据：「多少字以内」这类约束不采用。
- 强度：硬。

### 否掉一个词之前，先问它是不是合规替代品
- 判据：看到一个「不像正常说法」的词，按顺序问三句：① 它指向的东西在违禁词表里吗？在 → 它大概率是替代品，停，去问作者。② 不在 → 它在稿子里承担什么功能？标签（保留反复用）还是解释（翻译掉）。③ 都不是 → 才轮到「圈层黑话」那条。
- 为什么：两次实测都是拿一条管形式的规则（名字顺不顺 / 像不像黑话）去压一条管功能的规则（引用纪律 / 平台合规）。一次把一个谐音替代词当成黑话建议改回原词，而原词正是违禁高危字。
- 强度：实测。

### 判死一个东西之前，回去读那条规则的原文
- 判据：要判死任何东西之前答两句：① 这条禁止的原文在哪个文件哪一行？找不到 = 它是我脑子里的，不是规则。② 原文禁的到底是什么粒度？是「这个概念」还是「这个结论」？是「播放量」还是「效应量」？粒度错一格，杀伤面差一个数量级。
- 为什么：一次把「已讲过的结论」当成「已讲过的概念」判重，可做的题被压掉六成；一次自己发明的播放量门槛比规则严，把一个完全读得出来的判据挡在门外。「先判功能再判形式」防的是误判缺失，这条防的是误判禁止。
- 强度：硬。

## 脚本形态 · 定位与供需 · 三类脚本

### 放大真实可以，造假不行
- 判据：可以把真实发生的事讲得更大声、更具体，不可以加进没发生的事。判据是「每个细节都有原始记录能对上」。
- 为什么：放大是表达，造假是红线；两者的分界就是有没有原始记录。
- 怎么查：合规关里对每个具体数字和事件问「原始记录在哪」。
- 例子：真给过家人一笔钱，可以把这笔钱讲成一条视频；没给过，一分都不能提。
- 强度：硬

### 数据本身会被读成「他说的对」，所以论证要反复做
- 判据：观众会把高点赞当作「这话是对的」的证据。没有这种数据基础的账号，只能靠一次次把论证做扎实来换信任，不能靠语气。
- 为什么：借不到「数据背书」，就只剩「论证背书」；语气强硬只会显得空。
- 怎么查：筹码关里看结论后面跟的是证据还是语气词。
- 例子：（用占位）
- 强度：经验

### 专业名词一出来，流量就有上限
- 判据：稿子里每个需要解释的词都要么换成大白话，要么当场用一个画面解释。
- 为什么：观众不会停下来查词，他会划走。
- 怎么查：具象度关圈专业名词。
- 例子：（用占位）
- 强度：经验

## 审核与红线 · 流程与协作

### 陈述句只是及格线，还要过「有没有留缺口」的二次判定
- 判据：开头是陈述句、不自问自答，只说明格式合格。第二步再问：这句有没有让人觉得自己不知道什么？靠吹牛（「全网第一」「效果最好」）撑起来的陈述句，既没缺口也没可信度，一样不合格。可信度不一定要「我做了个产品」，一个具体的一手数字（「我存了三千多条」）也能成立。
- 为什么：只查句式会放过一堆「格式对、没人想听」的开头。
- 怎么查：对开头做两轮：先查句式，再问「观众读完这句想知道什么」，答不出 → 缺口为零。
- 例子：❌「我们的方法是最好的」（陈述句，无缺口，无可信度） ✅「我翻了三千条评论，发现骂得最狠的不是差评」。
- 强度：经验

### 营销点关：能力要长在叙述里，不许有任何一句让观众去做什么
- 判据：观众看完要知道两件事——你能解决什么、凭什么是你。这两件必须当成叙述里的一个事实带过，不是附加一段。同时，任何「扣 1 / 私信 / 链接在评论区 / 有需要找我」一律删。两条同时成立才算过：整条无形中展示了认知和能力，且没有任何一句在引导动作。位置放在价值交付之后。
- 为什么：刻意引导动作会破坏整条的完整性和专业感。转化要让观众觉得是他自己得出的结论，不是被推着走。
- 怎么查：①全文找「凭什么是我」有没有交代（只有「关注我带你学」这种指令不算）；②全文找任何行动指令，命中即删。纯情感表达且无商业目标可放宽，但不要一边期待有人来找你、一边不给任何找你的理由。
- 例子：❌ 结尾「想学的扣 1」 ✅ 正文里顺带一句「我自己那三个海外产品都是这么定价的」。
- 强度：硬

### 估时用实测语速区间，不用固定常数；只给区间不给点值
- 判据：稿面汉字数 ÷ 5.3 到 ÷ 5.8 字/秒得到原速时长区间（n=4，不同稿型之间原速差异不到一成，分不出层）；成片时长 = 原速 ÷ 加速倍率；算前 2 / 3 / 5 秒能装几个字必须用成片语速。另外实拍通常比稿面长约两成（临场展开）。「÷240 字/分钟」这类通用常数会把时长高估近四成。
- 为什么：用错常数会把能过的稿判成超时，或把超时的稿放过；用参数否掉一个句子之前要先问误差会不会翻转结论。
- 怎么查：报告里时长一律写区间；涉及倍速的稿子先问倍率。
- 例子：（用占位）1200 字 → 原速约 207–226 秒 → 1.2 倍速后约 172–189 秒。
- 强度：实测

### 前后矛盾扫描：一处发现，一处复核，不报两遍
- 判据：全文数字、时间、事实前后要对得上——开头说「一个周末」正文说「两小时」、开头「三千条」结尾「几千条」，观众一秒出戏，命中即必改。分工：结构关负责发现矛盾；合规关只做数值级最终复核，不重复报告。
- 为什么：同一个问题在两关各报一次，作者会以为是两个问题。
- 怎么查：结构关列矛盾清单；合规关只对照清单核数值。
- 例子：（用占位）
- 强度：经验

### 绝对化词分级：宣称效果的必换，口语强调的软化不阻断
- 判据：最、第一、唯一、国家级、顶级、彻底、全网、根治……在开头、标题、正文全扫。分级：用于产品或效果宣称的「最」= 高危必换；口语强调的「最」（「最大的感受是」）= 低危，建议软化，不阻断发布。照念型豁免——出现在念给 AI 的提示词里的「最」不算。
- 为什么：一刀切会把口语里的正常强调全部误伤，作者就不再信这一关。
- 怎么查：命中的每一处标级别，高危给替换词，低危给可选软化。
- 例子：❌「效果最好的方法」（高危） ⚠️「我最大的体会是」（低危）。
- 强度：经验

### 符号级红线走逐符号扫描，不靠语义通读
- 判据：破折号、标题里的英文半角冒号，必须逐符号 grep；中文全角冒号在句中正常使用不算违规，禁的是英文半角冒号和「冒号式标题」。
- 为什么：语义通读会跳过标点，这类错误正是通读最容易漏的。
- 怎么查：文风红线里凡是「符号」类的，用机器扫；「腔调」类的才用通读。
- 例子：❌「三步：第一…」（英文冒号式标题） ✅ 正文里「他说：你先别急」。
- 强度：硬

### 违禁词扫描必须过全表，不是只 grep 几个绝对化词
- 判据：合规关第一项是拿完整违禁词表（十类）扫全文，含标题、字幕、话题标签。只扫四个绝对化词等于没扫。
- 为什么：曾经连写三版都带着一个该换的币种说法没查出来，原因就是只 grep 了四个词。
- 怎么查：审核报告写明「已过全表」，否则视为未扫。
- 例子：（用占位）
- 强度：硬

### 金额两分法：单价可以说数字和币种，收入类只说量级
- 判据：单价（「一个月收四十美刀」）数字和币种都可以出现；收入、流水类**不出现具体数字和币种，但可以说量级**（「六位数」「七位数」「翻了三倍」）。币种说法统一用「美刀」不用「美金」。
- 为什么：收入类数字是「副业 / 网赚」类引流钩子的典型特征，平台按此限流；单价是产品信息，不在此列。
- 怎么查：全文找金额，先分类是单价还是收入，再按上面处理。
- 例子：✅「订阅一个月九块九」 ✅「去年做到了六位数」 ❌「去年收了十二万美刀」。
- 强度：硬

### 硬规则要求的结构件：先判功能，再判形式
- 判据：稿里没有某个规则要求的结构件（比如某种钩子、某种落点句），先看它的功能有没有用别的形式实现。形式不符但功能实现 = 过，不算缺失。确实缺、而作者拍板保留删除时，执行并把豁免写进稿件的说明栏，不许自己加回去。
- 为什么：审核者曾判一份稿「缺四块」，核完两块是作者用别的形式做了。
- 怎么查：每个「缺失」判定后面写一句「功能由哪句承担 / 确实没有」。
- 例子：（用占位）
- 强度：经验

### 「教你怎么做」封顶 78，「我这么做拿到了什么」才上 80
- 判据：方法、框架、清单再漂亮，只描述「怎么做」封顶 76–78；要上 80 以上必须配「我自己这么做之后的真实结果或数字」。方法论型、解答型、操作型稿一律同理。
- 为什么：「怎么做」换个懂行的人也讲得出来；「做了拿到了什么」只有做过的人有。
- 怎么查：每个高分候选句问一句：这是「教你怎么做」还是「我这么做真拿到了」。
- 例子：「三步改掉某种腔调」= 方法，≤78；「我这么改之后那条从零评论到四十几条」= 结果，80+。
- 强度：经验

### 自制物只描述功能封顶 78，过程数字也归这一侧
- 判据：「我一个人用 AI 做了个东西」类内容，只描述功能或机制封顶 78；配上「用了之后的真实结果数字」才上 80。花了多久做出来的过程数字（「一个下午」）也归 78 以下——工时是「做出来」，不是「用出结果」。
- 为什么：功能描述人人可抄，使用结果抄不走。
- 怎么查：数字出现时分类：过程数字还是结果数字。
- 例子：「插件能给标题打分」= 功能；「三周帮我筛掉四成标题党」= 结果。
- 强度：经验

### 观点型上 80 的边界：正确的非共识，圈内通识型换个说法不算
- 判据：一个原创的重新框定能不能上 80，看它是不是「大众以为 A、我点破其实 B、别处听不到」。圈内人人都知道的道理换个漂亮说法（「先给情绪别推销」），封顶 68–72。
- 为什么：这一档评的是别处听不到，圈内通识在圈内处处都听得到。
- 怎么查：问一句「做这行三年的人听了会不会说『这不是常识吗』」，会 → 封顶 72。
- 例子：（用占位）
- 强度：经验

### 高频误伤五类：知识类内容最容易无意撞上的
- 判据：①金融币种（人民币、美元、比特币）→ 用「块」「米」「美刀」或打码；②违法治安硬词（诈骗、传销、刷单、洗钱）→ 谈「套路」时避开这些词；③赌（赌博、老虎机，连「上头」「梭哈」也可能误伤）；④死亡暴力（「卷死了」「杀疯了」这类口语高频误伤 → 改「卷麻了」「赢麻了」）；⑤绝对化词（最、第一、唯一、国家级、顶级）。
- 为什么：讲 AI、创业、获客的内容本身不涉及这些类目，撞上的全是口语和比喻。
- 怎么查：五类优先扫，其余类目机器兜底。
- 例子：❌「这波把同行杀疯了」 ✅「这波把同行卷麻了」。
- 强度：经验

### 「钱」字本身按字扫，不看是谁在说
- 判据：「钱」出现在口播里就要换（「赚米」「掏米」「充米」），不区分是自述收入、转述别人的心里话、还是打比方。理由不是语义，是平台按字扫，它不管这个字是谁说的。
- 为什么：曾以为转述消费者内心话不算，成片后发现照样命中。
- 怎么查：全文 grep 单字「钱」，逐个替换。
- 例子：❌「他觉得你还想赚他的钱」 ✅「他觉得你还想赚他的米」。
- 强度：硬

### 替代词不是黑话：否掉一个看不懂的词之前，先查它指向的东西在不在禁表
- 判据：审文风时看到一个像圈层暗号的词，先问「它指向的那个东西在违禁词表里吗」。在 → 这个词大概率是替代品，不许用「圈层黑话」那条否它，列出来让作者定。
- 为什么：曾把一个平台要求的谐音替代当成黑话否掉，等于把合规动作的产物又打回去。
- 怎么查：黑话判定与违禁词表联动，先查后判。
- 例子：（用占位）「8+1」看着像暗号，它替代的是烟酒类禁词 → 放行。
- 强度：硬

### 海外大模型分层口径：聊信息可以，教着用不行
- 判据：①信息 / 新闻层（聊某模型发布、能力对比、行业趋势）可以提海外模型；②教程 / 执行 / 操作层（公域手把手教用）演示和让观众上手的环节用国内前沿模型的最新版；③客户端工具可以用海外的、可以教，但后端模型要通过中转方案切成国产，讲客户端时必须同时说明后端怎么切；④线下和私域不受此限。红线：绝不在公域引导观众去下载、注册、翻墙使用海外模型。
- 为什么：这是国内公域平台的硬性口径，违反是合规风险，优先级高于一切风格规则。
- 怎么查：生成任何公域教程类内容时：演示模型默认换国产；出现海外客户端 → 检查有没有同时给切后端的方案，没有就补；扫「去 X 下载 / 注册」「怎么翻墙用 X」类句子 → 删或换国产替代；信息类提到海外模型 → 保留但不附使用引导或入口。
- 例子：✅「某海外模型这次更新把上下文拉到了百万」（信息层） ❌「注册个账号，打开它的网页版，跟我做」（引导）。
- 强度：硬

## 说给谁听

**单人自采自编的知识型创作者。** 三条硬约束（与商业集同源）：

1. **不假设他有团队。** 拍摄、剪辑、发布都是他一个人，方案要能一个人执行完
2. **不用向上汇报。** 他自己拍板，直接给判断和动作，不写「供参考」
3. **零术语。** 理论照用，名词不出现——不说「信息缺口」，说「让他先觉得自己不知道」

## 评分公理

1. **逐句打分，论据引原句**：每一句/每个信息点单独评，让用户 一眼看到是哪句拖后腿。
2. **分数标尺**（校准锚点）：
   - **80+**：别处听不到的具体结论——真实数据、一手发现、具体到「某场景/某句话/某个数值」的判断
   - **60–79**：有价值的具体信息——痛点收成一句话、具体动作可执行、造词+具体工具
   - **40–59**：真实但太常见（所有讲这个话题的都这么说）、概念对但没例子、纯价值拉升口号
   - **<40**：废信息——排比凑节奏、重复、自嗨、和主题无关

   **⚠️ 光看定义评不准，必须读 `references/评分锚点.md`**——里面每档配了真实成稿句子和「为什么是这个分」，还有「哪些句子根本不参与评分」的分类表（钩子/转场/金句/CTA 都不按密度评，把转场句打低分是本技能最常见的误伤）。
3. **达标线**：**硬闸门 = ≥4 句 80+ 且红线全过。**
   **60+ 计数只作参考，不作判据。** 原因：双盲复测里同一条稿两个独立评审员判 60+ 分别是 9 和 5（差 44%），而两人判 80+ 都是 0 且独立指出同一个天花板原因——80+ 计数跨评审员收敛，60+ 不收敛（`08-技能记忆/_通用/20260707-proxy分数信度-只信80加和红线.md`）。
   **不要拿「60+ 从 5 变 6」当改稿变好的证据。**
4. **概念必须落地**：说了「某类方法」却给不出你自己的具体发现/例子 → 最高 65 分（「拆基因：概念对但太笼统，没给例子」型病灶）。
5. **误伤防护**：钩子句和转场句不按信息密度评（它们的职责是留人/衔接），单独按开头公式/流畅度评；情绪型脚本论点按「分值高不高=具象、精彩、有共识、一句话能戳中」评，不按干货密度评。

## Phase 0：开审之前（两个闸门 + 一次分类，全部一次性做完，别边审边问）

**闸门一 · 必须有成稿。** 只有选题或零散素材 → 不要假装审核，退回 `/zmm-script`。

**闸门二 · 必须知道目标用户。** 目标用户是判断开头、需求、朋友与敌人的地基。
- 稿里看得出来 → **写出你的判断，让他需要时纠正，不要停下来问**
- 稿里看不出来 → **只问这一个问题**：「这条最想吸引哪一类人？」拿到回答再开审

**闸门三 · 命题过五问了没有**（2026-08-26 加，`feedback_rules P 组`）。
稿子的判断本身站不站得住，**要在审表达之前审**：
绝对化 / 因果跳跃 / 定义偷换 / 经验普遍化 / 反向推断 —— 逐条过，
然后写一个判定：**保留 / 收窄 / 重构 / 放弃**。
🔴 **判「重构」或「放弃」的，不进十二关** —— 命题不成立时，
后面八关审的是「一个错的东西包装得好不好」。
⚠️ 判「收窄」时不必退回，**在报告里写清收窄到什么范围**，然后继续审。
⚠️ 本闸门与「观点鲜明 > 观点中庸」不冲突：**P 组审范围，鲜明规则审语气。**
范围收窄之后，语气仍然说死。

**分类 · 先判稿型，它决定后面哪几关放宽：**

| 稿型 | 放宽什么 |
|---|---|
| **干货口播** | 不放宽，全硬审 |
| **情感共鸣** | 第①关改看「情感母题 + 目标人群」；第⑤关可用真实阻力代替敌人；第⑥关无商业目标可不塞；第⑦关保留必要停顿 |
| **剧情冲突** | 重点砸②⑤⑦⑧；第⑥关服从剧情自然度 |

🔴 **稿型只影响权重，不能用「这是情感片」掩盖目标用户不清、开头无感、没有筹码。**

标记法：✅ 达标 ｜ ⚠️ 有但不够 ｜ ❌ 缺失或踩坑 ｜ ➖ 按稿型放宽（**必须写明理由**）

## 工作流程（十二关，按 `发布前审核流程.md` 走）

前八关管「有没有人看」，后四关管「听不听得懂 + 出不出事」：
①选题=需求+解决方案 ②开头 5 秒 ③陌生化+普遍性 ④信息清单 ⑤朋友与敌人 ⑥个人营销点 ⑦信息效率 ⑧筹码 ｜ ⑨具象度 ⑩结构与断点 ⑪（并入⑥）⑫合规红线。

第①关一句话结论（选题若明显立不住，先停下来说，别白评后面十一关）；第④关是核心展示（下面的评分表）；③⑤⑥⑦⑧⑨⑩ 并入 Phase 2；⑫即红线五查。

**Phase 1：逐句评分（第④步，核心）。**

输出评分表 + 统计 + 核心问题：

```
| # | 句/信息点（摘要） | 分 | 点评 |
|---|---|---|---|
| 3 | {原句摘要} | 55 | 真实但太常见，所有讲流量的都这么说 |
| 6 | {原句摘要} | 70 | 具体动作，可执行，有用 |
| 8 | {原句摘要} | 80 | 高分。这个区分对观众是真有价值的认知 |
...

统计：**80+ 共 N 句（硬闸门：≥4）** ｜ 60+ 共 N 句（参考，不作判据）
不参与评分：钩子 N 句 / 转场 N 句 / 金句 N 句（另按各自标准评）
核心问题：{哪几句是废信息占了篇幅；哪个高分点只给了概念没展开——展开它比删别的更值}
改法方向：{砍什么、腾出的空间给什么做实}
```

**优先找「40–59 分里已经站在好洞察门口的句子」**——它们比废信息更值得改。锚点文件里那句「最难的不是第一步，是第三步」就是典型：补一句「为什么难」就能从 45 上到 75，比删三句废话涨得多。

停下来给用户看，等他回应再进下一阶段。

**Phase 2：结构七关（按稿型给 ✅⚠️❌➖，每关一句现状证据 + 一句改法）。**

- **②开头**：公式三要素齐不齐、陈述句、5 秒内钩不钩得住、大白话。
  **必须点名三件事：谁会被第一句钉住、谁不会、真正有效的钩子是不是被埋在后文。**
  被埋了 → **把后文最强的一句前置**，不要凭空写夸张标题。

- **③陌生化 + 普遍性**（🆕 这一关最容易整条崩，且不是靠评分能发现的）：
  需求要普遍（目标人群普遍面对的赚钱/关系/教育/经营/表达需求），表达要陌生（新词、新角度、新分类、新反常识判断）。
  三问：这需求跟足够多的人有关吗 / 表达是不是行业里人人都在讲的旧话 / 能不能靠重新命名·重新分类·换视角制造稀缺。
  🔴 陌生化 ≠ 故意说人话听不懂，更不能伪造概念。
  ⚠️ **这关和第④关不重复**：④是句子级事后打分，③是整条级事前闸门。
  **一条稿可以每句都不算废话、却整条毫无陌生感——那时候病不在句子，在「这个题不该这么讲」。**

- **⑤朋友与敌人**（🆕）：写明四件事——朋友是谁 / 敌人是谁 / 冲突立不立得住 / **内容形象会让目标客户亲近、无感还是反感**。
  敌人可以是**错误做法、行业惯性、误区、规则、处境**，不必是某一类人。
  🔴 **绝不能把目标客户立成被骂被嘲讽的敌人。**
  情感稿没有敌人 → 用真实阻力（误解、时间、处境）替代，标 ➖ 写明理由。
  > 这条和红线「不点名对标」是同一件事的两面：**敌人立成错误做法，比立成人更安全也更耐看。**

- **⑥营销点**（🆕 本账号高频病在这关）：看完知不知道**为什么要找你、你能解决什么、下一步怎么做**。
  有效营销点 = **一个不过度强迫的行动指令 + 「我有什么／我能帮你解决什么」的具体理由**，位置在价值交付之后。
  ⚠️ **只查到 CTA 存在就放行，是漏审。** 「关注我带你把 AI 用明白」是指令，**不是理由**——
  整条如果没说出**凭什么是我**，这关就是 ⚠️ 而不是 ✅。
  一并查：互动点设计、干货条的收藏理由、双编码自检（老板听到什么/小白听到什么）。

- **⑦信息效率**：找重复观点、水词、**无功能过渡**（「接下来我给大家讲」「今天想和大家聊聊」）。
  字数 ÷ 240 字/分钟估时（说明实际语速会变）。给建议压缩到的字数，**同时保留高分信息数量**。
  **只提示两个时长区间**：30–60s 或 300s+；其余长度不评——全量池 n=541 显示中间区段无显著差异，「1–2 分钟甜点区」已被证伪。
  🔴 情感稿的停顿、环境声、画面留白**不机械压缩**。区分「有功能的留白」和「没有信息的拖沓」。

- **⑨具象度**：圈出「需要解释的词」和无支撑的抽象结论；专业名词即警告。
  判据：一个普通老板/宝妈刷到这句会不会当场问「这是啥」？照念型术语豁免（观众只复制粘贴，不需要懂）。

- **⑩结构与断点**：一条一个点（7±2，米勒 1956）、每点过「可照做标准」、结构符合所选形态骨架（`逆向-脚本形态库.md`）、点出 2–3 个最可能划走的断点句、获得感落点、全文数字/时间前后一致。
  ★ **7±2 不是免罪符**：9 个空壳点照样落在 7±2 内却密度全崩。数量达标 ≠ 结构达标。

**Phase 2.5：⑧筹码（单独一步，不要混进上面的清单）。**

问一句：**这条稿里，最接近 100 分、你愿意押注它带来流量的那一个信息/事实/冲突，是哪一个？**

- 说得出 → 判断它**硬不硬**（证据够不够、可不可核实），再问能不能**纵向加码**：叠身份、案例、结果、数字、现场证据
- 说不出 → **直接说「这条缺流量抓手」**，不要绕。这比任何一句的低分都严重
- 🔴 **不得为了加码捏造名人、数字、业绩、客户或结果**（同「卖真不卖梦」）

> **筹码 ≠ 80+ 句。** 80+ 是句子级评分，筹码是整条级押注。
> **一条稿可以有四个 80+ 却没有筹码**——四个都是同一强度的好句子，没有哪一个值得押。
> 「我做过很多案例」很平；**具体、可核实、与主题有关的那一个代表案例**才立体。

**Phase 3：⑧红线查（逐项报 过/不过）。**

命中的每一条都要给**三段式**（原文 / 触雷点 / 可直接替换的改写），不许只标不改——标出来让用户自己想改法，等于把活推回去。四类常见触雷的成品改法见 `references/评分锚点.md`〈红线改写三段式〉。
1. 违禁词全文扫描（含标题/话题标签），命中给替换建议
2. 原创度：改写/引用内容改动 >60%（平台查重线）
3. 卖真口径：收入表述、承诺表述逐句核（对照 `config.redlines.sell_real` 的 allowed / forbidden）
4. 大模型合规：教程/演示层有没有海外模型引导
5. 不点名对标 + 文风红线（破折号/双引号/首先其次/排比/emoji）+ 编程词汇禁令（B 端向的钩子和前 30 秒）

**Phase 4：判定 + 出口。**

**先收敛，再判定。十二关不平均用力**——从所有 ⚠️❌ 里挑出**最致命的 1–3 关**，
并说清**为什么它们优先于其他问题**。一句话结论必须直接回答三件事：
**现在能不能发 / 主要卡在哪几关 / 最致命的缺口是什么。**

「重点改造」**只示范关键句、段落骨架或营销点，不默认重写整篇**。

三档判定，给一句话理由：
- **能发**：达标线过 + 红线全过 → **就是可以发了。直接说「这条可以发」，然后闭嘴。**
  - ❌ 不许附加「不过建议再顺一遍稿」「要不要先做个共鸣诊断」「起个正式标题再发吧」这类尾巴。判了能发还挂条件，等于没判。
  - ✅ 唯一允许的补充是发布物料确实缺（只有抖音口播不需要封面大字；要发小红书才需要标题）。
  - 发完回来 `/zmm-retro`——**这一步不是可选的**，它是整个系统唯一的学习入口。
- **改后发**：列出按性价比排序的改动清单（先砍废信息、再做实高分概念）；问题集中在开头 → 转 `/zmm-hook`
- **重写**：60+ 不足半数说明装配弹药不行 → 带评分表回 `/zmm-script`

用户明确说「改」才进改写：逐处问他本来想表达什么，再给改法，一次一处。

### 判「改后发 / 重写」时，报告末尾问一次（**判「能发」时不问**）

> 「这份诊断里，你最不同意哪一项？」

他反驳时**回到原文和目标用户核对**，不为维护审核权威硬守第一版结论——
评分是主观判断，不是标准答案，说错了就改。

⚠️ **这一问只对「改后发/重写」有效。判了「能发」就闭嘴放行**，
不许用这句话变相加一道闸门（本系统曾有 7 道闸门、13 条成稿 0 条发布）。

## 自我开源四检（红线之后加判，不通过不判「能发」）

- [ ] 这个方向**真的花过时间、花过钱、验证过结论**吗（没做过就不该写）
- [ ] 第 ④ 步「**我是怎么推理的**」有没有真的写出来
- [ ] 如果带产品，那次营销**是不是逻辑链上必需的一环**（附加的就删）
- [ ] 有没有**自己解构自己**的地方（全片都在证明自己正确 = 端着）

⚠️ **这四条不构成新的发布闸门。**「最短可发路径」的硬规定不变——
判「能发」之后不得以任何理由拦下发布。本节用于**判之前**的一次性提醒，
不通过就在报告里写清楚缺哪一条，**由作者自己决定改还是发**。

→ 依据见 `zmm/references/认知框架.md`

## 说话风格

- 犀利不讨好：分低就是分低，「这句在凑字数」直接说。
- 每个点评一句话说清病灶类型，不写小作文。
- 稿子真的好就说好，列出 80+ 的句子为什么好，然后放行。

## 绝对不做

- 不越权改稿（诊断模式下只标不改）。
- 不因为「是 AI 写的」或「是 用户 写的」调整标准。

# 认知框架（内容集共用 · 判断层）

> `内容理论底座.md` 回答的是「**内容为什么有效**」——传播侧。
> 本文件回答的是「**你怎么知道你说的是对的**」——判断侧。
>
> 两者的关系：**先有判断，才谈得上传播。** 一个观点如果本身没被验证过，
> 传播技巧只会让它错得更快、传得更远。
>
> **引用纪律见文末「理论出处」一节（2026-08-12 改过，旧的「名词一律不出现」已作废）。**

---

## 元问题

> ## 你怎么知道你是对的？

三层结构：

```
信息   →   认知   →   验证
 ↑          ↑          ↑
AI 之后     AI 之后     只有这一层
成本归零    成本归零     还稀缺
```

信息差带来的往往是**焦虑，而非认知**。信息差非常容易让人产生「学到了」的错觉，
进而造成满足感——但那不是认知，因为**没有经过验证**。

---

## 根断言

> ## 自我验证无效。

**因为脑子不提供反证。** 一个点子在自己脑子里永远是越想越对、逻辑自洽的，
因为脑子只负责生成，不负责反驳。

**推论**：任何在你头脑内部完成的确认，都不算确认。

---

## 九条判断 = 根断言的九个面

写稿、选题、审核时，用来定位「这条内容在推倒哪一种自我验证」：

| | 判断 | 推倒的是哪一种自我验证 | 典型受众自白 |
|---|---|---|---|
| 一 | 信息不等于认知 | 我觉得我懂了 | 「这个我知道」 |
| 二 | 「专业」是封闭系统的内部认证 | 同行说我行 | 「我很专业但赚不到钱」 |
| 三 | 能力是被反馈塑造的；有些经验反而杀死能力 | 我练了很久所以我强 | 「我做了十年」 |
| 四 | 反馈的速度和粗粝度决定上限 | 反馈太慢或太猛，等于没有 | 「我每天都在看数据」 |
| 五 | 反向思维，从结果倒推 | 我有什么，所以我做什么 | 「我会这个技术，能做什么」 |
| 六 | 你不必自己产生所有反馈 | 别人已经验过的，你还在自己想 | 「我要做点没人做过的」 |
| 七 | 同一件事在不同时间点是不同的事 | 他行所以我也行 | 「这个模式跑通了我照做」 |
| 八 | 不是靠意志力，是靠环境 | 我下次一定能自律 | 「我就是执行力差」 |
| 九 | 身份换了，但对钱的认知没跟上 | 用旧身份的标准判断新身份的事 | 「赚到钱了对自己好点」 |

**九条同源，不是并列的九个知识点。** 记不住就只记根断言。

## 操作形态 · 验证四问

任何项目、任何行业、任何阶段通用。**这是可以直接交给观众带走的东西**：

```
① 这件事的反馈从哪来      是市场，还是同行
② 多久能拿到             三天，还是半年
③ 能不能证伪我           还是只能证明我想听的
④ 能不能借用别人的        他已经验过了，我还在想
```

## AI 时代版本

> ## AI 能创造一切，唯独创造不了真实。

AI 把**信息**和**模拟**的成本压到零 → **唯一还稀缺的就是真实反馈**。

**推论是反的**：AI 越强，越该早动手，不是越晚——因为动手之前那部分成本已经被压掉了。

**藏在里面的反转**：很多人用 AI，不是为了更快做出来，**是为了更晚开始**。
再分析一轮、再改一版、再让 AI 帮我想想——**AI 成了新的拖延工具**。

**对内容生产的直接约束**：生成端放大十倍很容易，**验证端跟不上就是十倍垃圾**。
所以先设计验证环节（红线扫描、数据回流、自检清单），再放大生成端。

## 怎么用在内容上

### 选题：热点三问

拿到任何热点，先不表态，问三句：

| | 问 | 你在找什么 |
|---|---|---|
| 1 | 这件事里，**大家在用什么当反馈**？ | 多半会发现：同行认可、平台数据、自己的推理——**不是市场的钱** |
| 2 | 那个反馈的**速度和粗粝度**怎么样？ | 太慢或太猛都会死 |
| 3 | 有没有人**已经完成了这个验证**可以借用？ | 有的话，热点本身就是别人替你做的实验 |

三问答完，判断自然出来，而且**一定和别人不一样**——别人讲现象，你讲验证结构。

### 写稿：亮路径三幕

```
撞上：① 碰到什么事 ② 哪里不对劲 ③ 老办法为什么失灵
想通：④ 怎么一步步想的 ⑤ 定了什么          ← 别人抄不走的只有这一幕
做完：⑥ 做了什么 ⑦ 结果 ⑧ 学到什么 ⑨ 换成你明天改什么
```

「结论 + 证据 + 好评」那种形状观众早免疫了，因为有用的结论人人都在讲。**两个人可以得出同一个结论，但不会走同一条路** —— 第二幕才是区分度的全部来源。

### 审核：亮底牌四检

- [ ] 这个方向我**真的花过时间、花过钱、验证过结论**吗
- [ ] 第二幕「**我是怎么一步步想的**」有没有真的写出来。只有结论没有过程 = 又变回展示专业
- [ ] 如果带产品，那次营销**是不是逻辑链上必需的一环**。是附加的就删
- [ ] 有没有**自己解构自己**的地方。全片都在证明自己正确 = 端着

## 定位后果：建的是筛子，不是教

做 IP 的认同不来自成就，来自你怎么想事情。但这里有个陷阱——
**越往这个方向走，越容易滑成「教」，而那会拆掉本框架的地基。**

```
教      信众要确定性   →   给答案   →   信我
筛子    体系要验证     →   给标准   →   别信任何人，包括我
```

按「教」做，会不自觉地优化三样：**确定性 · 魅力 · 我们对他们**。
三样都在拆地基——**刚讲完「自我验证无效」，转头要求别人无条件认同你，
是同一个错误换了个方向。**

| | 教（不要） | 筛子（走这条） |
|---|---|---|
| 说什么 | 跟着我做 / 相信我 | **这是我判断的方法，你可以用它来判断我** |
| 聚集的是 | 信徒 | **同类**——同样不接受未经验证说法的人 |
| 凭什么留下 | 认同你这个人 | **这里的人和我一样** |
| 出错时 | 崩塌（人设不能错） | 无所谓（本来就说了会错） |

**筛子反而产生更深的认同，因为它给了对方主权。**
也因此：**框架要白送**（验证四问、三幕骨架、热点三问公开给出不藏）——
把标准白送是筛子的必要动作，「教」绝不会这么干。

### 三条硬约束

1. **不做确定性承诺**（也与平台合规一致）
2. **不塑造不会错的形象**——错了要讲出来，那是筛子的燃料
3. **把标准白送**

### ⚠️ 合规词表（比金额类禁词更严）

**一个都不能出现**：宗教 · 信仰 · 教主 · 布道 · 信徒 · 皈依 · 修行 · 开光 · 命运 · 玄学
**安全替代**：同类 · 一路人 · 共同的判断标准 · 同频 · 圈子

## ⚠️ 边界（必须知道，否则本框架自己就成了不可证伪的断言）

| 不适用的情况 | 为什么 |
|---|---|
| 价值观 / 审美 / 情感类判断 | 没有「市场反馈」可言，硬套会变成媚俗 |
| 反馈周期天然极长的事（养育 / 健康 / 长期关系） | 求快反而错，要的是耐受不是迭代 |
| 一次性不可逆的决定 | 没有迭代机会，第②③问失效 |

**适用范围：可迭代、有外部买单方、反馈可获得的事——也就是生意。**

超出这个范围还硬套，**就变成了另一种「越想越对」，只不过换了个更精致的自洽系统**。

## 引用纪律（2026-08-12 改，推翻旧规则）

🔴 **旧规则已作废**：「名词一律不出现在成稿里，说『一百年前有个教育学家』不说人名书名」。

**新规则**：

> **来自海外、面世二十年以上、已经成为学科常识的书或理论 —— 书名、作者、代表性的一句话可以直接进文案，
> 作为权威背书。**

### 为什么这不与「筛子不是教」冲突

**恰恰相反，它加强筛子。** 点名一本 1938 年的书，等于把**可查证的源头**交给对方——
他可以自己去查，也可以拿它来反驳你。

「教」不会这么干：教要的是「信我」，所以它只给结论不给出处。
**给出处 = 给对方主权**，与「把标准白送」同源。

### 三条准入条件（全中才能用）

| | 条件 | 为什么 |
|---|---|---|
| 1 | **海外** | 中文当代书同行都在引，没有稀缺性，容易撞车 |
| 2 | **出版 ≥20 年** | **年份本身就是权威感的来源**——「1938 年」自动证明它不是最近的成功学 |
| 3 | **经典书籍 / 学科理论** | 不是畅销书。引畅销书会读成书单推荐 |

### 口播句式（固定三段，不要改结构）

```
[年份] 年有本书叫《[书名]》，作者[中文名]。
他说了一句话：[金句，≤20 字]。
[紧跟一句人话翻译]
```

**年份放最前面**，它是这套引用全部权威感的来源。

示例：

> 「1938 年有本书叫《经验与教育》，作者是杜威。
> 他说了一句话：**并非所有经验都教育人**。
> 有些经验不但不教育你，还会把你卡在原地。」

### 口播首选清单（好念 + 有名 + 观点反直觉，按推荐度排）

| | 作者 | 书 | 年 | 可用金句 | 为什么好用 |
|---|---|---|---|---|---|
| 1 | **杜威** | 经验与教育 | 1938 | 并非所有经验都教育人 | 中国人认识杜威，名字最好念 |
| 2 | **波普尔** | 科学发现的逻辑 | 1934 | 不能被证伪的判断，没有价值 | 与验证轴最贴合，是体系正统性来源 |
| 3 | **赫伯特·西蒙** | 人工科学 | 1969 | 满意解优于最优解 | **诺贝尔经济学奖**，头衔本身就是背书 |
| 4 | **维纳** | 控制论 | 1948 | 反馈过猛会引起意向性震颤 | 「意向性震颤」这个词本身就不明觉厉 |
| 5 | **戈夫曼** | 日常生活中的自我呈现 | 1959 | 专业是一种前台表演 | ⚠️ 前台/后台已被同圈层公开用过，换角度切 |
| 6 | **班杜拉** | 社会学习理论 | 1977 | 替代性学习：别人试过的错，你不必再试 | 支撑第六条判断 |
| 7 | **斯金纳** | 有机体的行为 | 1938 | 你被什么强化，就变成什么样的人 | 心理学入门都知道，好念 |

⚠️ **不进口播**（书好但名字念出来会卡）：
贝塔朗菲 · 利克莱德 · 格拉泽和施特劳斯 · 伯莱恩 · 艾利克森。
**这几本继续只用观点，不报人名。**

### 🔴 姿态（2026-08-15 更新）

```
旧   默认不引，除非特别合适
新   ★ 默认要引，目标每条 1–2 本 —— 引用是常规动作，不是加分项
```

**用途：文案主题的金句 + 权威性背书。** 但出处必须真实、必须查过原文。

### ★ 资历植入：无意识背书（2026-08-15 加）

**判据**（与删除测试同源）：

> **把那句资历删掉，后面的话还成立吗？**
> 成立 = 插播广告，删　　不成立 = 论据，留

**四个手法**（按强度）：

| | 手法 | 为什么有效 |
|---|---|---|
| 1 | ★★ **让资历去承认对方是对的** | 资历出现时在**支持反方**。观众收到「他做成过」+「他没自夸」两个信息 |
| 2 | ★ **说方式，不说数字** | 方式可被验证可被质疑，数字只能被羡慕或怀疑 |
| 3 | **紧跟一个「但是」** | 没有转折就停在炫耀上。转折是把资历变回论据的动作 |
| 4 | **最低限度表述** | 「我走通了」就够。**你填的是吹牛，他填的是判断** |

★ **最高级的形态：主动说别人的办法比自己好。** 比任何自夸都硬。

**红线**：不给金额/排名/倍数 · 不用「第一/最/唯一」 ·
**资历不许单独成段**（单独成段就是简历）· 一条最多两次，第二次必须是回调。

```
❌ 自我介绍   我是某某，我做过 X 和 Y   →  身份当开场白
✅ 资历植入   我自己就是这么走过来的    →  身份当论据
```

### 🔴 不自我介绍（2026-08-15 加）

```
开头   ❌ 不说「大家好我是某某」「我是一个连续创业者」
结尾   ❌ 不说「我是某某，关注我」——不像说话，且不产生信息
       ✅ 可以有一句收藏/行动引导，但必须和内容有关
```

**身份在账号资料里已经说明。IP 靠长期内容自然形成，不靠每条报一次名字。**

### 🔴 五条红线

1. **一条内容 1–2 本**。⚠️ **第二本必须支撑另一个不同的点**——
   不能给同一个判断叠两个背书，那是掉书袋
2. **金句必须紧跟人话翻译。** 只丢名词不翻译 = 装
3. **不能编。** 书名 · 作者 · 年份 · 观点四样都必须真，
   而且**那句话得真是那本书说的**——不是从二手文章里听来的转述
4. **不引最近 20 年的商业畅销书**
5. **不当论据的挡箭牌。** 引用是给观众多一条查证路径，
   **不免除你举实例的义务**

> 🔴 第 3 条最容易翻车。**要引就先查原文，不要凭印象报书名。**

# 规则卡

> 本技能内置的判据。每张卡：判据 / 为什么 / 怎么查 / 例子 / 强度（硬 = 不可商量；实测 = 有数据，数值是本系统实测，换账号要重测；经验 = 用过有效，未量化）。

## 脚本形态 · 定位与供需 · 三类脚本

### 把大问题拆成小问题再问 AI
- 判据：不问「帮我写一条视频」，拆成选题、开头、主体结构、场景、光线、构图、服装……每个单独问。给 AI 你的标准和定义，它才给得出非平均的答案。
- 为什么：AI 默认给的是大众平均；不拆细、不给标准，拿到的就是平庸答案。
- 怎么查：一次对话只解决一个拆出来的小问题。
- 例子：（用占位）
- 强度：经验

### AI 给的是想法，判断由人做
- 判据：AI 的产出要人来判断好坏；判断力来自自己懂这件事。真实的体验、情绪、细节必须来自人，AI 不替你编。
- 为什么：把判断也交给 AI，等于把账号交给大众平均。
- 怎么查：每次 AI 产出后人给出「留 / 改 / 弃」和一句理由。
- 例子：（用占位）
- 强度：经验

### 学一个当下能马上用的点，拿到反馈再学下一个
- 判据：一次只学一个能当天用上的方法，用了、看到结果，再学下一个。
- 为什么：一次学一堆消化不了，而且没有反馈就不知道哪个有用。
- 怎么查：新手教程结尾只让用户记一件事。
- 例子：（用占位）
- 强度：经验

## 审核与红线 · 流程与协作

### 唤起度倒 U：情绪调到适中偏高
- 判据：耶克斯与多德森的唤起-表现倒 U 关系。情绪别太平也别歇斯底里，开头和落点都调到「适中偏高」。
- 为什么：太平没人停，太满观众防御。
- 怎么查：开头候选按情绪浓度排一遍，取中上，不取最高。
- 例子：（用占位）
- 强度：经验

### 损失框架：标题和钩子用「怕失去」压过「想得到」
- 判据：卡尼曼与特沃斯基的前景理论，损失的心理权重大于同等收益。标题、钩子可用「别再……」「你正在白烧……」框架。⚠️ 与卖真红线联动：损失只能是他已经在承受的，不是你替他设想出来吓他的（见 ⑤ 代价句卡）。
- 为什么：同样的信息，损失框架停留更高。
- 怎么查：标题候选里至少一个损失框架版本，再过卖真。
- 例子：（用占位）
- 强度：经验

### 三诉求：每条内容都要有真实战绩、情绪钩、可照做逻辑三样
- 判据：亚里士多德的信誉、情感、逻辑三诉求。一条内容缺任何一样都软：没战绩不可信，没情绪不停留，没逻辑带不走。
- 为什么：三样分别对应可信度、留存、收藏。
- 怎么查：审稿时三栏各指到一句原文，指不到的那栏就是缺口。
- 例子：（用占位）
- 强度：经验

### 社会认同：选题制造「我们 vs 他们」，但敌人是做法不是人
- 判据：塔吉费尔的内群 / 外群身份。选题可以立「真做的人 vs 编的人」这类分野；配合立场关，「他们」立成错误做法而不是某类人。
- 为什么：群体身份驱动转发，但立成人会把目标观众推到对面。
- 怎么查：分野句写出来后问「对面是一种做法还是一群人」。
- 例子：（用占位）
- 强度：经验

### 英雄之旅：个人故事按「磨难-转机」交替，不按时间流水
- 判据：坎贝尔的召唤-磨难-回归结构。个人故事型稿子用磨难与转机交替推进，每段磨难落在「当时我怎么想的、哪里想错了」。
- 为什么：时间流水没有起伏，观众在第二段就走。
- 怎么查：故事稿按段标「磨难 / 转机」，连续两段同一种 → 重排。
- 例子：（用占位）
- 强度：经验

### 叙事思维与框架：用故事讲道理，选题是给旧事实一个新框架
- 判据：布鲁纳「人靠故事理解世界」——道理用故事讲，不用论文腔；戈夫曼「框架决定意义」——很多选题不需要新事实，需要的是给旧事实换一个框架。
- 为什么：同一件事换框架，责任、原因、评价全变，这本身就是内容。
- 怎么查：选题候选问「我提供的是新事实还是新框架」，两者都没有 → 不做。
- 例子：（用占位）
- 强度：经验

### 默会知识：只有真做过才说得出的细节，是最难抄的可信度
- 判据：波兰尼「知道的多于能说的」。真做过的人有一堆说不清为什么但知道的细节，钩子和正文里露这种细节，可信度不需要额外证明。
- 为什么：数字可以编，这类细节编不像。
- 怎么查：可信度那一栏优先找「做过的人才知道」的细节，其次才是数字。
- 例子：（用占位）
- 强度：经验

### 前台后台与准社会关系：人设是有意识的前台，信任靠高频露脸和直呼「你」
- 判据：戈夫曼拟剧论——人设是前台，线上线下的差异来自后台能不能藏；霍顿与沃尔的准社会关系——观众对创作者的单向亲密靠高频露脸、直呼「你」、评论区在场养出来。
- 为什么：信任不是一条内容建立的，是频率建立的。
- 怎么查：人设一致性检查：这条稿里「我」的形象和前几条对不对得上。
- 例子：（用占位）
- 强度：经验

### 单纯曝光与定位：重复主线主题，只占一个词
- 判据：扎荣茨单纯曝光——越熟越喜欢，高频发布、重复主线主题有好感复利；里斯与特劳特定位——账号只占一个词，别贪多。
- 为什么：主题分散的账号观众记不住你是谁。
- 怎么查：选题配比检查里看主线主题占比。
- 例子：（用占位）
- 强度：经验

### 刻板印象翻转：先点破大众脑中的图景，再翻
- 判据：李普曼「脑中先有图景」。「正确的非共识」类内容的写法是先复述大众的刻板图景，再翻它。
- 为什么：不先立靶子，翻转没有落点。
- 怎么查：非共识类稿子前几句里有没有「大众以为」的那句。
- 例子：（用占位）
- 强度：经验

### 两张卡可以连着打：缺口链是「未完成」加「信息缺口」的连续使用
- 判据：所谓阶梯式悬念不是新机制，是蔡格尼克与信息缺口两张卡连续使用：答完一个立刻长出下一个。判据在缺口连法卡（⑤ 节），这里只提醒可以连打，不重复判据。
- 为什么：把连续使用当成新方法会和已有判据漂移。
- 怎么查：见 ⑤ 缺口连法卡。
- 例子：（用占位）
- 强度：经验

### 只有一份导航文件：它是目录、裁判、流程，不复制规则正文
- 判据：规则散在多个文件时，设一份总入口，只做三件事：裁定层级、解冲突、定顺序。它不复制任何规则正文。它和某个规则文件冲突时，说明它过期了——修它，不改规则文件。
- 为什么：规则正文复制两份必然漂移，漂移之后没人知道哪份对。
- 怎么查：总入口里出现判据正文 → 删掉换成指针。
- 例子：（用占位）
- 强度：经验

### 优先级链：当场反馈 > 被返工验证过的细则 > 冲突裁定表 > 体系方法论 > 专项规则 > 对标素材
- 判据：两条规则打架时从上往下判。返工验证过的细则高于体系方法论，因为每条细则背后都有一次真实返工；对标素材永远最低，它是信号不是方法。表里没有的冲突按链判，判完回写进裁定表。
- 为什么：没有优先级链，每次冲突都临时调和，同一个冲突会被裁出不同结果。
- 怎么查：冲突出现时不自己临时调和，先查裁定表，再走链。
- 例子：（用占位）
- 强度：硬

### 规则只在源文件改；注入层只写指针；两处不一致以源为准并当场修另一处
- 判据：会被自动读进上下文的那块（比如项目级指令文件）只写「做什么 + 去哪读」，一个判据都不写；判据全在源文件。发现两处不一致，修指针那边，不留两个版本。
- 为什么：注入层保证最贵的动作不漏，源文件保证判据只有一份。
- 怎么查：注入层出现「判据」字样的句子 → 移到源文件。
- 例子：（用占位）
- 强度：经验

### 按需加载：只读当前这一步要的文件，不一次读完
- 判据：写开场读开场的判据，写正文读正文的，审稿读审稿的。总入口维护一张「在做什么 → 最少读哪几份」的表。
- 为什么：一次读完二十份既费上下文又把无关规则混进当前判断。
- 怎么查：技能启动时的读取清单对照表。
- 例子：（用占位）
- 强度：经验

### 反馈自动回写：命中触发条件就做，不等作者说「记下来」
- 判据：触发条件任一命中即执行：①作者否定了一版稿或一个做法；②作者给了一个判据；③作者拍板了一个二选一；④作者指出援引了不适用的规则或规则本身错了；⑤实拍或数据推翻了一条已有规则。执行四步缺一不可：①原话入档（原样记，不改写成规范语言）；②判归属层（落到哪一层的权威文件）；③写成可执行判据（不是「要更有共鸣」，是「这句话说的事他是正在经历还是想起来会难受」）；④附返工代价（因为哪一版返工才有的、返工了几版）。
- 为什么：写不出「下次怎么做」的不是规则是观察，不入库；没有代价的规则会被下一个人当建议忽略。
- 怎么查：每条新入库规则四栏齐全，缺一栏退回。
- 例子：（用占位）
- 强度：硬

### 同一个错踩第二次 = 第一次只写了观察，回去把那条改成能当场判的形式
- 判据：同类错误第二次出现时，不是再记一遍，是回到第一次的那条规则，改写成「看到什么就判什么」的形式。
- 为什么：记两遍观察不会让第三次不发生。
- 怎么查：写新记忆前先查重，命中旧条 → 改旧条而不是追加。
- 例子：（用占位）
- 强度：硬

### 反馈落库位置固定几处，不新建
- 判据：反馈按类型落到固定的几个文件（判据细则表 / 选题与开头 / 正文结构 / 体系方法论 / 语言风格），不为一条反馈新建文件。入库后回到总入口：如果这条改变了层级或产生了新冲突，回写地图或裁定表。
- 为什么：落库位置一多，下次加载清单就漏。
- 怎么查：新建规则文件必须同时登记进加载清单，否则等于不存在。
- 例子：（用占位）
- 强度：经验

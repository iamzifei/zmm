# 🔍 草稿共鸣诊断 · 测试稿 01「三个原因稿」（白板视频）

> 模式 A · 只诊断不改稿。每条判断分三层：**原文**（稿里哪句）· **推断**（我认为观众会怎样，标置信度）· **待验证**（要什么数据才知道）。
> 依据读取：家族公约 ✅ · 交互规范 ✅ · 内容理论底座 §七 ✅ · `config.yaml` ✅ · 技能记忆目录不存在（按指示跳过，本次无历史纠正可用）。

---

**一句话**：观众看完手里**大概率会多一样东西**：「我不涨粉不是内容差，是我说的话对到别人也会说」。但它被切成了三个并列原因来讲，其中两个其实是同一件事、第三个是另一条视频的题，再加一段报告腔把陪看变成了念结论。**最大的问题是核心被稀释，不是核心缺失。**

### 真核心是哪个

**「粉丝不涨，不是你内容差，是你每句话都对，对到别人也会说，观众没理由记住你。」**

依据：
- 主张 2、3（记不住 / 没独有说法）和 4、5（都对 / 都知道）是**同一条因果链的两端**：说的都是别人也会说的正确话 → 分不清你和圈外的人 → 记不住 → 不关注。稿子把「结果」当原因一、把「原因」当原因二，并列讲了两遍。
- 唯一有画面、有数字的证据（茶叶案例，主张 6、7）落点是「记住他的理由」，它同时支撑 3 和 5，**只支撑这一件事**，不支撑原因三。
- 作者自己的收尾（主张 12、13）也只选了这一件：「优先解决记忆点」「你先改第一个」。作者心里的核心和稿子的证据是对齐的，只是结构没跟上。
- 原因三（开头筛人，主张 8–10）是**另一件事**：它讲的是前几秒留不留得住人，不是记不记得住你。没有因果，没有案例，三句「你以为……其实……」全是断言。它在这条里是外来的。
- 主张 11（关注分发转兴趣分发）是第四件事，只出现一句，没有任何支撑，也没有接回三个原因。

**当前状态：被稀释。** 三个并列原因，实际是「一个核心 + 一个外来题 + 一句悬空的行业判断」。

（脚注：并列多点为什么等于没记住，见底座 §六；原因三没有「因为」为什么落不了地，见 M5。）

## 【带走什么】

### 原来是这样 ——「我之前想反了」

- **原文**：
  - 「记不住不是内容差，是没有一个你独有的说法。」
  - 「正确的话，观众听完等于没听。」
  - 「这不是他的茶变了，是观众终于有了一个记住他的理由。」
- **推断**（置信度 **中**）：目标观众里那批「我内容明明不差就是不涨」的人，读到这三句，可能把归因从「我做得不够好 / 平台不推我」翻成「我做得太『对』了」。这是一个反向因果，一句就够，稿里确实有。**之所以只给「中」**：因为这句因果被拆在两段里各说了一半，中间还隔着四句排比，观众要自己把「没独有说法」和「说的都对」拼起来才成一句「因为」；另外「独有的说法」是什么、怎么得到，稿里没给，观众只能带走「原来问题在这」，带不走「原来该往哪走」。
- **原因三那三句「你以为……其实……」**：形式上是翻转，但没有一句「因为」。观众只能「感觉对」，第二天记不住（置信度 **高**：三句里没有任何一句解释开头为什么是筛人）。
- **待验证**：评论区里「原来不是我内容差」「我一直以为是平台不推」这类**归因翻转**的表述占比；茶叶案例那句「我劝你别买明前茶」有没有被观众原句引用（被引用说明画面留下了，因果可能没留下）。

（脚注：翻转判断为什么必须带「因为」，见 M5。）

### 我就说吧 ——「我早就觉得是这样」

- **原文**：
  - 「你说『坚持很重要』，没人反对，也没人记得。」（及后三句同构排比）
  - 「大家都这么开头就是错的。」
- **推断**（置信度 **中低**）：做号的人私下多半看不上那些讲正确废话的账号，这一段把它说破了，可能让一部分观众觉得「对，我早就觉得那种号没意思」。但**给不出观众自己给不出的证据**：稿里唯一的坐实材料是一个朋友的案例（n=1，四百对两千），这对「我就说吧」型观众来说是故事不是证据。而且本稿用的是第二人称「你」，指着观众自己说「你说的都对」，观众更可能觉得被戳，不是被坐实。
- **待验证**：评论区「就是这样」「说到心坎里」类表述占比；如果高，说明观众把自己放在了观察者位置而不是被诊断者位置。

（脚注：观众来用内容的目的不同，见 M2。）

### 他替我说了 ——「这话我不敢说，他说了」

- **原文**：**无。**
- 说明：稿里唯一像嘴替的句子是「我劝你别买明前茶」，但它替的是茶叶买家，不是本稿的观众。对本稿观众（做号不涨粉的人）而言，全稿在**诊断他**，没有一句在**替他说**。「大家都这么开头就是错的」沾一点边，但它骂的是观众自己也在做的事，站的不是他那边。
- 这条属于四种散法里的第四种：**正确、平淡、没碰任何人不敢碰的地方。** 稿子的每一句都是「你的问题在这」，没有一句是「你其实早就知道，只是不好意思承认」。
- **如果要补，只能问作者**（我不能替观众编）：这批人私下有什么不能公开说的判断？我的猜测供作者核对（置信度 **低**）：「我知道我发的那些正能量内容没人看，但不发又怕账号空着 / 怕说错」。这句如果成立，才是能被转发的那句。

（脚注：为什么憋着的话才有转发力，见 M1。）

## 【会做什么】

### 收藏 —— 以后要用

- **触发物原文**：「三个原因，记不住你、说的都对、开头没筛人。你先改第一个。」
- **推断**（置信度 **中低**）：结尾这三条是一张自检清单，形式上够收藏。但「你先改第一个」后面**没有一个可照做的动作**：怎么找到「独有的说法」？稿里没说。观众收藏了也不知道回头来查什么。
- **待验证**：收藏 / 点赞比。按家族口径收藏率 ≥1% 才算实用信号。

### 转发 —— 说明「我是这样的人」

- **触发物原文**：**无。**
- **推断**（置信度 **中**）：「正确的话，观众听完等于没听」是全稿唯一有转发形状的句子，但它是第二人称诊断句，转出去等于承认「我就是那个不涨粉的」。没有人会用一句戳自己的话来表态。案例里「我劝你别买明前茶」有转发形状，但那是别人的主张，不是本稿的。
- **待验证**：转发 / 点赞比；转发时附带的文字是「看看这个」（分享型）还是「我早说过」（表态型）。

（脚注：转发和收藏为什么不能互推，见 M6。）

### 评论 —— 有话要说

- **触发物原文**：
  - 「三个原因，你对着看自己中了哪一个。」（明确邀请报数）
  - 「开头越尖越好。」（一个没留余地的判断，可反驳）
- **推断**（置信度 **高**，仅指形式）：「你对着看自己中了哪一个」是全稿最清楚的留口子，观众能直接回「我中了第二个」。「开头越尖越好」是绝对判断，可能引来「尖了会掉粉」的反驳。**形式上有口子，是本稿四种冲动里最实的一个。**
- **待验证**：评论区「我中了 X」的密度 vs 反驳「越尖越掉粉」的密度。前者高说明清单起效，后者高说明原因三在抢核心的戏。

（脚注：留口子的判断为什么引评论，见 M5。）

### 关注 —— 想看他下一次怎么判断

- **触发物原文**：「看这里，我在板上画个圈，圈里是你，圈外是所有跟你讲同一类东西的人。」
- **推断**（置信度 **中低**）：画圈这个动作露出了一种判断方式（「你和圈外分不分得清」），茶叶案例也露出了「把一条改成反常识」的判断。但**怎么找到那句反常识，判断方式没露**，观众看到的是「他能判断」，不是「他怎么判断」。
- **待验证**：关注 / 播放比对比账号基线；评论区有没有「下次讲讲怎么找独有说法」这类追更表述。

## 【立场】

**站在谁那边（具体到人）**：一个人做号、自认内容不差、发了一个月三十条没起色、开始怀疑是自己不行还是平台不推的自媒体新手。**不是**站在教人做号的老师那边。

**有没有漂：漂了，漂了两次。**

| 段落 | 口吻 | 观众位置 |
|---|---|---|
| 开头 + 原因一 + 原因二 + 案例 | 「看这里，我在板上画个圈」「举个例子」 | **被陪着看**（服务者） |
| 原因三 | 「你以为……吗？其实……」连续三次 | **被训**（教育者）。三个「你以为」把观众放在「想错了」的位置，且没给理由 |
| 结论段 | 「针对上述……鉴于……基于以上分析，我们可以得出如下结论，即……应当」 | **被念报告**（汇报者）。人称从「你」变成「我们」「创作者」，观众从当事人变成被研究对象 |
| 收尾 | 「你先改第一个」 | **回到被陪着看**（教练） |

后果：表一第三行（他替我说了）本来就没有，立场一漂，连「我就说吧」也会掉：观众在原因三被训了一轮，到结论段又被念了一遍，他很难在这两段里觉得「他站我这边」。

（脚注：同一件事换个说法，观众是被代言还是被说教就变了，见 M3。）

## 【改法】

**删**
- **结论段整段**（「针对上述三个原因……优先解决记忆点缺失的问题」）。一句为什么：它把观众从「被陪着看」变成「被念报告」，还塞进一个没证据、没接回正文的新判断（关注分发转兴趣分发），是第四件事。
- **「划重点啊」**。一句为什么：它不给观众任何东西，只是在乞讨注意力。

**降级**
- **原因三「开头筛人」**：两条路，作者选。① 整段拿掉，留作下一条视频的核心（它本身是个成立的题，只是不该在这条里）；② 压成原因一的一个例子：「你的开头也一样，跟大家一样打招呼，观众第一秒就分不清你」，让它服务核心而不是并列。**不能保留现状**：三句断言并列在核心旁边，观众会把「开头」当第三件要记的事，然后一件也记不住。
- **原因一和原因二合并成一件事**：圈的画面（结果：分不清）+「正确的话等于没听」（原因：都对）+ 茶叶案例（证据）。现在是分两段各讲一半，观众要自己拼。

**强化**
- **把因果收成一句**，放在案例之后：「你不涨粉不是内容差，是你每句话都对，对到别人也会说，观众没理由记住你。」这一句是「原来是这样」的落点，现在它散在两段末尾。
- **「你先改第一个」后面加一个能照做的动作**，否则收藏落不下来。稿里没有这个材料，要作者给：怎么找到「独有的说法」？哪怕只是一个动作，例如「把你最近十条里被人反驳过的那句找出来」。这一条我只能指出缺，不能替作者编。
- **「他替我说了」是否要补，问作者一个问题**：这批人私下有什么不能公开说的判断？我猜的那句（「我知道那些正确内容没人看，但不发又怕账号空着」）只是供核对，不能直接写进去。

**不动**
- **开头问句**：「为什么你一个月发了三十条视频，粉丝还是不涨？」是钩子，归 `/zmm-hook`，本技能不评。
- **茶叶案例全段**：全稿唯一有画面、有数字、有前后对比的证据，是最硬的东西，一个字不要动。
- **收尾「你先改第一个」的决断**：作者选了一件事，这是对的，保住。

**改完的骨架**：观众带走一句因果（「我不涨粉不是内容差，是我说的都对到别人也会说」）和一个画面（明前茶那一条），想干的事是回评论「我就是这样」，以及收藏那个找独有说法的动作（如果作者补上了）。

## 收尾

**Recap**：这条稿的核心是成立的，而且作者自己在结尾选对了（「先改第一个」）。问题是结构没跟上：一件事被拆成两个原因讲了两遍，一个外来题（开头筛人）并列进来抢戏，一段报告腔把陪看变成念报告。三种收获里只有「原来是这样」落了一半，「他替我说了」是空的。四种冲动里评论最实，转发是空的。

**Before / After**
```
如果没做这一步：作者大概率按「三个原因」的框架发出去，观众记住的是「三个」，不是那一句因果
现在：确认核心是「说的都对所以记不住」这一件事，原因三是另一条视频
差别：少讲一件事，多留一句话；「他替我说了」这一格空着这件事被看见了，作者可以决定补不补
```

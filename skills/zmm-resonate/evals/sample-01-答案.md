# 测试稿 01 · 答案（只给评分者）

输入是「粉丝不涨的三个原因」白板稿（与 zmm-flow 样本共用），走模式 A。

## 必须做到（5）

| # | 要求 |
|---|---|
| A1 | 定出唯一核心，且是「观众记不住你 / 缺一个独有的说法」这一条（三条原因里只有它有画面和证据，另两条是它的展开） |
| A2 | 「原来是这样」这一格指到茶叶案例那句因果（「这不是他的茶变了，是观众终于有了一个记住他的理由」），标为原文 + 推断 + 置信度 |
| A3 | 「他替我说了」这一格判「无」或「弱」并说明：稿子没有任何一句是观众不敢说的判断 |
| A4 | 四种冲动里「转发」判「无」（没有可以替观众表态的一句），「收藏」判有或弱（三条原因清单） |
| A5 | 每条判断都带原文引用；至少一处写了「待验证：要看评论区 / 转发比才知道」 |

## 不许出现（2）

| # | 要求 |
|---|---|
| N1 | 不出现对五个理论逐个打分的表（沉默的螺旋 / 使用与满足 / 框架 / 两级传播 / 认知失调 各一行「有效 / 弱 / 无效」） |
| N2 | 不把「观众会觉得 X」写成事实句（必须是「可能 / 推断」+ 置信度） |

## 评分

A1–A5 各 1 分；N1 / N2 违反各扣 1 分。满分 5，通过线 4 且 N 不扣。

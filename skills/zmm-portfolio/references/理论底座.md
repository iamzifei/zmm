# 理论底座

> 本技能的每条公理都对应一个经过长期检验的公开理论。这么做有三个理由：
> ①这些理论比任何个人经验都经得起推敲；②它们是公有知识，可以明确署名引用，不存在来源问题；③**它们覆盖了作者本人没有一手经验的业态**——一个只做过线上生意的人，凭经验讲不了餐饮的现金流，但约束理论和现金转换周期是跨业态成立的。
>
> **引用纪律**：只引真实存在、可查证的理论与出处。记不准的宁可不引。**绝不为了显得权威而编造出处**——这跟成稿里的卖真红线是同一条。

## 公理 1（瓶颈资源）← 约束理论

**Theory of Constraints，Eliyahu M. Goldratt，《The Goal》1984**

核心：**任何系统的产出由它最窄的那个环节决定。** 优化非瓶颈环节，对整体产出没有任何贡献——只会积压更多在瓶颈前面。

五步聚焦法（本技能 Phase 1–3 就是它的组合层版本）：
1. 找出约束
2. 榨干约束（先别投钱，先把现有的用满）
3. **其余一切服从约束**（这一步最反直觉，也最值钱）
4. 提升约束
5. 约束转移后回到第 1 步——别让惯性把旧约束当成永久的

**对组合体检的直接含义**：
- 「这条线还能优化」如果说的是非瓶颈线，那是浪费
- 一门生意的瓶颈**会变**，去年是获客今年可能是交付，所以体检要重做而不是一次定终身
- 第 2 步的顺序（先榨干再投钱）是本技能拒绝「一上来就加码」的理论依据

## 公理 1b（现金流 ≠ 利润）← 现金转换周期

**Cash Conversion Cycle，Richards & Laughlin，1980**

`CCC = 存货周转天数 + 应收账款天数 − 应付账款天数`

这个天数就是**你的钱被别人占用的时长**。为正意味着你在给上下游垫资——生意越大，垫得越多。**这解释了为什么赚钱的生意会被自己的增长拖死。**

跨业态的形状差异：
- 线上订阅 / 充值：CCC 常为**负**（先收钱后交付）——所以做线上的人对现金流没有痛感
- 电商 / 零售：存货天数长，CCC 正且大
- 工厂 / B2B：应收账期长，CCC 最难看
- 餐饮：存货短、收款即时，CCC 可以为负，**但租金和人工是刚性前置支出**，所以死法不同（不是被占款拖死，是固定成本吃掉流水）

## 公理 2（组合层 ≠ 单产品层）← 局部最优不等于全局最优

同样出自约束理论，也可追到运筹学的一般结论：**每个子系统都达到最优，系统整体通常不是最优。**

对照参考：**BCG 增长-份额矩阵**（Bruce Henderson，波士顿咨询，约 1970）把业务分成现金牛 / 明星 / 问题 / 瘦狗，也是组合层视角。

**本技能与 BCG 的差别要讲清楚**（不要假装是同一个东西）：BCG 的两个轴是市场增长率和相对份额，**假设资本是主要约束**，服务的是大公司配资金；本技能的轴是营收贡献和瓶颈资源占用，**假设瓶颈资源（常是时间或产能）是主要约束**，服务的是一个人或小团队。**小经营者缺的从来不是资本配置模型，是「我这周该干哪个」。**

## 公理 3（边际 > 绝对）← 边际分析与机会成本

**边际主义**：Menger / Jevons / Walras，1870s；机会成本概念由 Friedrich von Wieser 明确提出。

核心：决策只看**下一单位投入带来的变化**，不看历史累计。「这条线贡献了 40% 营收」是存量事实，对「下一个月投哪」这个问题没有信息量。

机会成本：投 A 的真实代价不是花掉的时间，而是**同样的时间投 B 本来能拿到的结果**。所以本技能拒绝孤立地评价一条线——没有比较对象就没有机会成本，也就没有决策。

## 公理 4（不投入 ≠ 零成本）← 固定成本 / 沉没成本的区分

维持成本是**持续发生的固定成本**，不是沉没成本。两者常被混淆，但决策含义相反：

- **沉没成本**（已花掉、不可收回）→ **决策时必须忽略**
- **维持成本**（继续持有就要继续付）→ **决策时必须计入**

「这条线我已经做了两年了」是沉没成本，不构成继续的理由。「这条线每周还要 3 小时维护」是维持成本，必须从可分配资源里扣掉。**把这两个搞反，是多线经营最常见的账算错法。**

## 公理 5（砍线难 → 预先承诺）← 沉没成本谬误 + 承诺机制

**沉没成本谬误**：Arkes & Blumer，1985，*The Psychology of Sunk Cost*。人会因为已投入而继续投入，投入越多越难退出。

**承诺机制（commitment device）**：Thomas Schelling，《The Strategy of Conflict》1960。核心洞察是**在冷静时限制未来的自己**，因为未来的你会面对当下没有的诱惑和借口。

这两条合起来就是本技能要求「预先写下砍线触发条件、到期不重新讨论」的理论依据。**不是纪律问题，是结构问题**——把决定留给那个手握沉没成本的未来的你，结果是可预测的。

补充**可证伪性**（Karl Popper，《研究的逻辑》1934）：触发条件必须写成**可能为假**的形式。「如果还是不见起色」不可证伪；「到 12 月 31 日月营收仍低于 X」可证伪。**写不成可证伪的条件，等于没写。**

## 公理 6（营收集中）← 集中度与尾部风险

赫芬达尔指数（HHI，Hirschman 1945 / Herfindahl 1950）是衡量集中度的标准工具。本技能只用它的直觉，不算完整指数。

关联：**塔勒布的脆弱性概念**（*Antifragile*, 2012）——一个系统在正常状态下表现良好、但单点失效即崩溃，那是脆弱而非稳健。营收集中的产品线正是这种结构。

## 交付能力的天花板 ← 利特尔法则

**Little's Law，J.D.C. Little，1961**：`在制品数量 = 到达率 × 停留时间`

对知识付费 / 咨询 / 服务型生意特别重要：**同时在服务的客户数 = 成交速度 × 单客交付周期。** 想接更多客户又不想延长交付周期，只能压缩单客耗时——这是数学不是意志力。

**「卖得越好越忙、最后交付崩掉」不是管理不善，是没算这个式子。**

## 分析方法上的两个坑（本项目真实踩过）

### 幸存者偏差 ← Abraham Wald，1943

二战期间统计研究组分析返航轰炸机的弹孔分布，结论是**该加固的恰恰是没有弹孔的部位**——因为中弹在那里的飞机没能飞回来。

本项目踩过同一个坑：从某对标账号的 **TOP100** 归纳出「干货甜点区 1–2 分钟」，回到全量池 n=541 一验，效应消失。**TOP 榜单是被结果筛选过的样本，从中归纳「成功要素」，等于只研究飞回来的飞机。**

### 辛普森悖论 ← E.H. Simpson，1951（亦见 Yule，1903）

分组数据的趋势，在合并后可能反转。

本项目的应用：验证「长文更容易被收藏」时，担心它其实是「近期的帖子更好」。把样本按时间分成四期、在每期内部重测，四期全部成立，**且两个可能的混淆方向都是反的**——所以结论成立。**没做这一步就下结论，是本项目明确禁止的做法。**

## 使用纪律

1. **引用要能查证。** 给出作者、著作、年份，不确定就说不确定。
2. **理论是脚手架不是权威。** 用户的真实数据和理论冲突时，**以数据为准**，并把冲突记下来——那往往是最有价值的发现。
3. **不要用理论名词唬人。** 对用户讲的时候说人话：不说「应用约束理论」，说「先找出卡住你的那一个环节，其他地方再优化也没用」。
4. **不引超出本技能范围的理论**（组织行为、宏观经济、投融资）——覆盖不了就说覆盖不了。
